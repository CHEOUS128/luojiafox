## luojiamaster（自定义客户端）

基于 [ACE_RM26_CustomClient](https://github.com/ACE-Algorithm/ACE_RM26_CustomClient) 二次开发。

**功能**：接收官方赛事引擎的比赛数据与机器人第一视角图传（HEVC 1080p60），并通过键鼠操控实车。

### 快速开始

直接运行：`luojiamaster/程序/luojiamaster.exe`

**前置条件（缺一不可）**：
1. 裁判端 `RoboMasterEngine` 已启动并登录
2. 官方选手端 `RoboMasterClient` **版本 ≥ 12.0.0.213**（关键）
3. 选手端图传画面正常显示
4. 选手端 P 面板 → 键鼠控制来源 → 选「自定义客户端」
5. luojiamaster 与选手端登录**同一机器人 ID**

**登录地址**：
- 选手端同机：`127.0.0.1:3333`
- 选手端异机：`选手端IP:3333`

### 快捷键

| 键 | 功能 |
|---|---|
| `Esc` | 进入 / 退出比赛模式 |
| `H` | 主画面 / 第二视角切换 |
| `I` | 画面 180° 翻转 |
| `P` | 设置面板（鼠标灵敏度） |

### 相对 ACE 原版的改动

共 4 处功能性修复，详见 `luojiamaster/改动清单.diff.md`：

1. **键盘采样**：`IsKeyPressed` → `IsKeyDown`（原版键盘掩码恒为 0）
2. **鼠标光标**：锁定 + 逐帧回中 + 原始位移累积（原版鼠标顶到边缘即失控）
3. **180° 旋转**：CPU 逐像素交换 → GPU UV 翻转（原版每帧 207 万像素 CPU 开销）
4. **灵敏度**：默认 1.0 → 0.4，滑块范围 0.05~3.0

### 已知限制

- 控制响应延迟高于官方选手端（多一跳 MQTT 转发）
- 视频为 CPU 软解，未启用硬件加速

详见 `luojiamaster/完整复现指南.md` 第 6 节。
