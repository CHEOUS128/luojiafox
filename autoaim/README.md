## 目标平台：26 赛季全向轮步兵

本版本专门为 **26 赛季全向轮步兵** 调校，涉及以下平台相关参数：

| 项目 | 配置 |
|---|---|
| 兵种 | 步兵（全向轮底盘） |
| 相机 | 大恒（Daheng）/ 海康（HikRobot）/ MindVision，代码支持多品牌 |
| 相机分辨率 | 1280×1024 |
| 运行平台 | Jetson Orin（ROS2 可选） |
| 下位机 | STM32（见 `lower-machine/`） |
| 通信 | 串口（自定义 16 字节协议） |

**注意**：以下参数与具体车辆强相关，换车必须重新标定：

- `yaw_offset`（弹着点校准，2.5m 实测值）
- `pitch_offset`（垂直校准）
- 弹速（当前写死 27.0，planner 钳到 22）
- 相机内参与手眼标定

## 核心改动（相对 10.04 版本）

### 1. 双模型跟踪（装甲板 KF）

在 `Target` 中并行新增一个**装甲板线性卡尔曼滤波**（6 维：x/y/z 及速度）。
平动时（|ω| < 0.7 rad/s）用装甲板 KF 的速度替代整车 EKF 速度，避免旋转模型污染。

### 2. 修复 3 个实际缺陷

| 编号 | 问题 | 修复 |
|---|---|---|
| P1 | 装甲板 KF 的 Q 矩阵结构错误（单位阵×常数，速度估计被压死） | 改为按 dt 规范缩放 `[dt⁴/4, dt³/2; dt³/2, dt²] × Q` |
| P2 | 两套「平动修正」互相打架 | 去掉 freeze，只保留一套机制（对齐上科大 radium_limit） |
| P3 | 图像中心硬编码为 `(720, 540)`，实际相机 1280×1024 | 改为 `(640, 512)` |

### 3. 可观测性

新增 `[DualModel]` 日志，输出 `armor_vy / vehicle_vy / w / r`，便于上车对比两套速度估计。

### 4. 三阶指令管道（备用）

`gimbal.cpp` 已具备发送「角度 + 角速度 + 角加速度」（32 字节帧）的能力，
受 `three_order_enable` 开关控制，**默认关闭**，待电控协议就绪后开启。

## 编译

### 环境

- Ubuntu 22.04
- OpenVINO（神经网络推理）
- Ceres（优化）
- 相机 SDK（大恒 / 海康 / MindVision，按实际相机选装）

### 步骤

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

> 完整编译说明见 `my_lf_INF_20261013/readme.md`。

### 运行

```bash
./standard_mpc ../configs/standard3.yaml
```

> 生产构建目标为 `standard_mpc`（无可视化，使用 MPC Planner）。
> 全量构建会因 `fire_test.cpp` 失败，建议只编译指定目标。
