## 已被推翻的结论（别再照着做）

| 当时的说法 | 现在的事实 |
|---|---|
| 「按 CTRL 云台锁死/粘底盘」 | 不是云台故障：固件把 CTRL 当复位键，经 CAN `0x04` 第 4 字节让底板 `System_Reset()`，整车重启。**现在不烧新版，使用上避免按 CTRL** |
| 「3pin 的 TX/RX 接反了」 | CH 确认那根线一直在正常用，不可能接反。**不要再提** |
| 「裁判端 UI 抢 USART6 的 DMA」 | 这版固件里 `referee_usart_task` 创建是注释掉的，`UI_ReFresh` 永不执行 |
| 「遥控器掉线会 `RC_restart()` 关 USART6」 | `detect_task.c` 里的注册是注释掉的，全工程无调用点 |
| 「电控把控制帧和视频帧耦合了」 | 不成立，见上面 10-24 那份 |
| 「`video_forward.c` 里有 `System_Reset()`」 | 云台板那份已经注释掉，真正执行复位的是**底板** `gimbal_task.c` |
