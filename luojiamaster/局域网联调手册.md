# 局域网联调方案（依据官方《赛事引擎联网操作手册 202604》）

> **本文分三部分读：**
> **第一~十节** = 最基础的两机方案（1 台官方端 + 1 台自定义客户端），所有网段/路由器/启动顺序的来龙去脉在这里。
> **第十一节** = 官方赛场 5 台电脑的完整摆法（1 台引擎/裁判端 + 2 台官方选手端 + 2 台自定义客户端，PC-1~PC-5）。
> **第十二节** = ⭐ **我们现在用的四台电脑摆法**（2 台官方端各自带引擎/选手端 + 2 台客户端，
> 引擎与步兵选手端同机）。**现场动手只看第十二节**，一页打印速查在 12.9。
> 第一次搭也可以先扫一眼第十一节，那里把每个网段为什么这么定讲得更细。
>
> 硬件：小米路由器（2 个 LAN 口 + 2.4G Wi-Fi）、USB 转网卡、网线若干。
> **不用交换机** —— 除非路由器 LAN 口不够接三台电脑（见 11.2 的说明，只在 `192.168.1.x` 那一层加）。
> 依据：`赛季规则/2026规则/RoboMaster赛事引擎联网操作手册（202604）.pdf`
> 　　　`RoboMaster 2026 高校系列赛通信协议 V2.0.0` 第 2 章

## 〇、官方规定的三个网段，各管一件事

| 网段 | 谁用 | 出处 |
|---|---|---|
| `192.168.1.0/24` | **裁判系统局域网**：路由器 `192.168.1.1`，裁判端主机 `192.168.1.2`，**机器人主控连 Wi-Fi 拿这个网段** | 联网手册方案 1 |
| `192.168.12.0/24` | **自定义客户端链路**：服务器 `192.168.12.1`，客户端 `192.168.12.2` | 通信协议第 2 章 |
| 其它私网网段 | **广域网（外网）**，给引擎登录/联网测试用，须避开上面两个 | 联网手册方案 1/2 |

**一句话**：路由器负责 `192.168.1.x`（主控 + 引擎），PC-A 的 USB 网卡负责 `192.168.12.x`（选手端 ↔ 自定义客户端）。

## 一、接线

```
                    ┌──────────────────────────────┐
     校园网/外网 ───▶│  小米路由器 WAN（可选）        │
                    │                              │
                    │  Wi-Fi 2.4G ──▶ 机器人主控    │
                    │                              │
                    │  LAN①              LAN②       │
                    └───┼───────────────────┬──────┘
                        │                   │
                   网线① │                   │ 网线②（可空）
                        ▼                   ▼
        ┌──────────────────────────┐   （备用）
        │ PC-A  引擎 + 官方选手端    │
        │                          │
        │  主板网卡 192.168.1.2     │
        │  USB 网卡 192.168.12.1 ───┼──网线③──▶ PC-B
        │  VT13 接收端插 USB 口      │            │
        └──────────────────────────┘            ▼
                                        ┌──────────────────┐
                                        │ PC-B 自定义客户端 │
                                        │ 192.168.12.2     │
                                        └──────────────────┘
```

**插法**：

1. **路由器 LAN① → PC-A 主板网卡**（网线①）
2. **PC-A 的 USB 网卡 → PC-B**（网线③，直连，不用交换机）
3. 路由器 LAN② 空着（**上赛场时这里接 PC-3 官方英雄端**，见第十一节）
4. 路由器 INTERNET/WAN：有外网线就接，没有就空着（见第三节）
5. PC-A 的 VT13 接收端插 USB 口

**为什么不用交换机**：两台电脑之间只走一根直连（上赛场时是两根，各自一对）；路由器 LAN 口一台一个，物理上不可能成环——你之前那台交换机的报警问题自然消失。

## 一之二、方案 B：外部无线局域网 + 网线直连客户端

> **适用场景**：手上有一个已配置好的外部无线局域网（**不能接网线**），
> 同时希望**自定义客户端与官方选手端之间走有线**（图传更稳）。

### B.1 接线

```
        ┌─────────────────────────────────────────────┐
        │  外部无线局域网（已配置，不可接网线）          │
        └──────────────────┬──────────────────────────┘
                           │ Wi-Fi
                           ▼
             ┌──────────────────────────────┐
             │ PC-A  引擎 + 官方选手端        │
             │  Wi-Fi     : 自动获取          │
             │  有线网卡  : 192.168.12.1      │
             └──────────────┬───────────────┘
                            │ 一根网线直连
                            ▼
             ┌──────────────────────────────┐
             │ PC-B  自定义客户端            │
             │  有线网卡 : 192.168.12.2       │
             └──────────────────────────────┘
```

**为什么这样接**：客户端与选手端之间是千兆有线，1080p60 图传不受无线干扰。
选手端到引擎那一段仍走外部无线（无法避免）。

### B.2 设置 PC-A（双网卡）

| 网卡 | 用途 | 设置 |
|---|---|---|
| Wi-Fi | 连外部局域网（通引擎/外网） | **自动获取 IP**（不要改） |
| 有线网卡（主板或 USB 网卡） | 连 PC-B | 静态 `192.168.12.1` |

有线网卡填写：

| 项目 | 填写 |
|---|---|
| IP 地址 | `192.168.12.1` |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | **留空**（不抢 Wi-Fi 的默认路由） |
| DNS | 留空 |

### B.3 设置 PC-B（单网卡）

| 项目 | 填写 |
|---|---|
| IP 地址 | `192.168.12.2` |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | **留空** |
| DNS | 留空 |

### B.4 先检查网段冲突

在 PC-A 上执行 `ipconfig`，看 **Wi-Fi 拿到的地址**：

- 如果 Wi-Fi 网段是 **`192.168.12.x`** → ❌ 与有线网卡冲突。
  把两台电脑的有线网段一起改成别的，例如 `192.168.13.1` / `192.168.13.2`，
  客户端登录地址也跟着改成 `192.168.13.1:3333`。
- 其它网段（`192.168.1.x`、`10.x.x.x`、`192.168.31.x` 等）→ ✅ 不冲突，按上面设置即可。

### B.5 验证

PC-B 上执行：

```cmd
ping 192.168.12.1
```

**通了就说明有线这一段没问题。** 不通时先关两台电脑的防火墙再试。

### B.6 跃点数（只在出问题时调）

正常情况下**不需要动**，因为有线网卡网关留空、不参与默认路由。

如果出现“有线能通但上不了网/连不上引擎”，按官方做法调整：

1. 网络连接 → 右键网卡 → 属性 → IPv4 → **高级**
2. 取消勾选「自动跃点」
3. **Wi-Fi 网卡跃点数 = `10`**（外网优先）
4. **有线网卡跃点数 = `20`**

### B.7 启动

1. PC-A：启动 `RoboMasterEngine.exe` 并登录
2. PC-A：启动 `RoboMasterClient.exe`，服务器填 **`127.0.0.1`**（引擎同机），登录
3. PC-A：按 `P` → 键鼠控制来源 → **自定义客户端**
4. PC-B：启动 `luojiamaster.exe`，登录填 **`192.168.12.1:3333`**
5. PC-B：机器人 ID 与选手端一致

### B.8 这套方案的局限

| 限制 | 说明 |
|---|---|
| 主控上线依赖外部局域网网段 | 主控只能连 2.4G Wi-Fi（密码 `12345678`、WPA2），且必须拿到 `192.168.1.x` 才能找到 `192.168.1.2`。外部局域网不是这个网段 → 主控上不了线 |
| 选手端 ↔ 引擎仍走无线 | 官方手册不建议裁判端主机无线连局域网，数据偶发抖动时原因在此 |
| PC-A 需要两块网卡 | 一块 Wi-Fi + 一块有线（主板网卡或 USB 网卡） |

## 二、配置小米路由器（详细步骤）

> 官方原文（《赛事引擎联网操作手册 202604》方案 1）：
> “使用 **2.4G**（裁判系统局域网只支持 2.4G）带 WAN 口以及 LAN 口的无线路由器（可以使用家用路由器）。”
> “路由器 LAN 口 IP 设置为 **192.168.1.1**，SSID 自定义，**密码设置为 12345678**，加密方式选择 **WPA2-PSK**，并**开启 DHCP** 功能。”
> “WAN 口 IP 须**避开** `192.168.1.0/24` 和 `192.168.12.0/24`。”

小米路由器的菜单叫法和普通路由器不一样，下面逐个菜单写清楚。

### 2.1 准备工作（先做，避免改完找不回路由器）

1. 用**网线**把电脑接到路由器任意 LAN 口（带一个点/两个点的口）
2. 把电脑网卡改成 **自动获取 IP**（这一步只是暂时用来登录路由器，后面会改回静态）
3. 记下路由器的**管理密码**；忘了就按 2.7 恢复出厂

### 2.2 登录管理页

1. 浏览器地址栏输入 **`miwifi.com`** 或 **`192.168.31.1`**
2. 回车，出现小米路由器登录页
3. 输入管理密码，点登录

> ⚠️ 如果显示的是"设置向导""欢迎使用"等初始化页面，说明路由器是出厂状态或刚重置，
> 先按 2.7 的初始化流程走完，再回来做 2.3。

> ⚠️ 如果提示"无法访问"，检查：
> - 电脑是否已拿到 `192.168.31.x` 地址（`ipconfig` 查）
> - 是不是连错了 Wi-Fi（连的是别的路由器）
> - 换 `192.168.31.1` 试试

### 2.3 第一步：改 LAN 网段为 192.168.1.1

这是**最关键**的一步，决定主控和裁判端能不能在同一网段。

1. 登录后，看页面右上角，点 **「高级设置」**
   （有的版本左侧是竖排菜单，直接找「高级设置」）
2. 在高级设置里找 **「局域网设置」**
   （也可能叫「LAN 口设置」「内网设置」「DHCP 服务」）
3. 找到 **「局域网 IP 地址」**（或「路由器 IP」「LAN IP」），当前显示 `192.168.31.1`
4. 改成 **`192.168.1.1`**
5. 子网掩码保持 **`255.255.255.0`**
6. 确认 **「DHCP 服务」是「开启」**（有的版本叫「DHCP 服务器」，开关打开即可）
   - 地址池范围不用改，默认的 `192.168.1.100` ~ `192.168.1.249` 就行
7. 点 **「保存」**

> ⚠️ **别找错菜单**：
> - **「上网设置」里的「自动获取 IP / 静态 IP」是 WAN（外网）的设置**，跟 LAN 网段无关，改它没用
> - **「Wi-Fi 设置」里只能改 Wi-Fi 名称和密码**，也没有 LAN IP
> - **LAN IP 只在「高级设置 → 局域网设置」里**，页面标题通常叫「局域网设置」或「LAN 设置」
> - 如果在初始化向导里，向导不包含 LAN IP，必须**先完成初始化**，再进高级设置改

**保存后会发生什么：**

- 页面提示需要重启，点确认
- 路由器重启约 **1~2 分钟**，期间电脑会断网
- 重启后路由器地址变成 **`192.168.1.1`**，`miwifi.com` 多半打不开，改用新地址

**让电脑拿到新地址**（路由器重启完后执行）：

```cmd
ipconfig /release
ipconfig /renew
ipconfig
```

检查「默认网关」是否变成 `192.168.1.1`。如果还是 `192.168.31.1`：
- 断开再插一次网线
- 或者把电脑网卡临时设静态 `192.168.1.10` / 掩码 `255.255.255.0` / 网关 `192.168.1.1`，直接访问 `192.168.1.1` 管理页

### 2.4 第二步：设置 2.4G Wi-Fi（主控要连这个）

1. 浏览器重新打开 **`192.168.1.1`**，登录
2. 点 **「常用设置」→「Wi-Fi 设置」**
   （有的版本直接首页就有「Wi-Fi 设置」）
3. **先处理双频合一**：
   - 如果看到 **「双频合一」** 开关，**关掉**
   - 关掉后会分成「2.4G Wi-Fi」和「5G Wi-Fi」两个独立设置
4. **2.4G Wi-Fi 设置**：

| 项目 | 填写 | 说明 |
|---|---|---|
| 开关 | **开启** | 主控只能连 2.4G |
| 名称（SSID） | 任意，例如 `RM_LAB` | 建议用英文/数字 |
| 密码 | **`12345678`** | **官方规定，不要改** |
| 加密方式 | **WPA2-PSK** | 有 `WPA2/WPA3` 混合选项时优先选纯 `WPA2` |

5. **5G Wi-Fi 设置**：

| 项目 | 填写 |
|---|---|
| 开关 | **关闭**（官方要求局域网只用 2.4G） |

> 如果路由器**没有关闭 5G 的开关**（部分低端型号）：
> 那就保持 5G 开着，只是**别让主控连 5G**。主控一般只支持 2.4G，会自动连 2.4G。
> 但要把 2.4G 的密码设成 `12345678`，加密设成 WPA2。

6. 点 **「保存」**，Wi-Fi 会重启（约 10~20 秒）

**验证 Wi-Fi 设置**（用手机或电脑）：

1. 搜索 Wi-Fi，能看到 `RM_LAB`
2. 输入密码 `12345678` 能连上
3. 连上后 `ipconfig` 应拿到 `192.168.1.x` 地址

> ⚠️ 密码必须是 `12345678`。主控固件里这个密码是写死的，改了就连不上。
> ⚠️ 加密方式必须是 WPA2。选 WPA3 主控可能连不上。

### 2.5 第三步：WAN 口设置（外网，可选但引擎需要）

1. 管理页 → **「常用设置」→「上网设置」**
2. 看 **「上网方式」**：

| 你的情况 | 选择 |
|---|---|
| 有网线从校园网/上级路由器过来 | **「自动获取 IP（DHCP）」** |
| 有固定 IP 的上网账号 | 「固定 IP」，填运营商给的地址 |
| 需要账号密码拨号（PPPoE） | 「宽带拨号」，填账号密码 |
| **完全没有外网** | 保持「自动获取」，WAN 空着（引擎外网测试会失败，见第三节） |

3. 保存后，看 **「上网状态」**：
   - 显示「已联网」→ 外网通了
   - 显示「未连接」→ 检查网线插的是 WAN 口（不是 LAN 口）

**检查 WAN 口 IP 有没有冲突**（官方要求）：

在管理页首页或「上网设置」里看 WAN 口拿到的 IP：

| WAN 口 IP | 处理 |
|---|---|
| `192.168.1.x` | ❌ **冲突**，必须改：上网方式改「固定 IP」，手动填一个别的网段，如 `10.10.10.2`（网关 `10.10.10.1`） |
| `192.168.12.x` | ❌ **冲突**，同上处理 |
| 其它（如 `10.x.x.x`、`172.x.x.x`、`192.168.0.x`） | ✅ 可以使用 |

> 为什么必须避开：`192.168.1.x` 是裁判系统局域网，`192.168.12.x` 是客户端链路。
> WAN 口如果占了这两个网段，会造成路由冲突。

### 2.6 第四步：确认 DHCP 和无线参数汇总

改完后，逐项核对：

| 项目 | 正确的值 | 在哪看 |
|---|---|---|
| LAN IP | `192.168.1.1` | 高级设置 → 局域网设置 |
| 子网掩码 | `255.255.255.0` | 同上 |
| DHCP | 开启 | 同上 |
| 2.4G Wi-Fi | 开启 | 常用设置 → Wi-Fi 设置 |
| 2.4G 密码 | `12345678` | 同上 |
| 2.4G 加密 | WPA2-PSK | 同上 |
| 5G Wi-Fi | 关闭（能关的话） | 同上 |
| WAN IP 网段 | 不是 `192.168.1.x`、不是 `192.168.12.x` | 常用设置 → 上网设置 |

### 2.7 恢复出厂 / 初始化（忘记密码或设置乱掉时）

**恢复出厂：**

1. 路由器**通电状态**下，翻转看背面或底部
2. 找到 **Reset** 小孔（或按钮）
3. 用牙签/回形针按住 **10 秒**，直到所有指示灯一起闪烁，松开
4. 等 **1~2 分钟**，路由器重启完成

**重新初始化：**

1. 电脑/手机连路由器的默认 Wi-Fi
   （小米默认 Wi-Fi 名形如 `Xiaomi_XXXX`，默认无密码或密码在背面标签）
2. 浏览器打开 **`miwifi.com`**
3. 跟着向导走：
   - **同意用户协议**
   - **上网方式**：选「自动获取 IP（DHCP）」
     - 提示"未检测到网络"时，选 **「继续」/「跳过」**（我们不一定接外网）
   - **Wi-Fi 名称和密码**：名称随便，密码先设成 `12345678`（后面还要按 2.4 核对）
   - **管理员密码**：设置一个，**记下来**
   - 完成
4. 初始化完成后，**回到 2.3 改 LAN 网段**

> ⚠️ 初始化时如果让你绑定小米账号，可以跳过。
> ⚠️ 初始化时如果问"是否开启双频合一"，**选否/关闭**。

### 2.8 常见卡点

| 现象 | 原因 | 处理 |
|---|---|---|
| `miwifi.com` 打不开 | 电脑不在 `192.168.31.x` | `ipconfig` 看地址，或临时设静态 `192.168.31.10` |
| 登录页没有「高级设置」 | 版本不同，菜单在左侧 | 找左侧竖排菜单的「高级设置」 |
| 找不到「局域网设置」 | 可能是「内网设置」「DHCP 设置」 | 逐个点开看 |
| 改 LAN IP 后管理页打不开 | 路由器已换地址 | 用 `192.168.1.1`，并先 `ipconfig /renew` |
| 找不到关闭 5G 的选项 | 型号不支持 | 保持 5G 开着，只确保 2.4G 密码 `12345678`、加密 WPA2 |
| 保存后 Wi-Fi 连不上 | 密码改错了 | 用网线连上重新改 |
| 改了 LAN IP 后上不了网 | 正常，外网看 WAN 设置 | 按 2.5 检查 WAN |
| 提示"IP 地址冲突" | 改的地址和别的设备撞了 | 换一个，如 `192.168.1.1` 被占就重启路由器再试 |
| 只看到「自动获取 IP / 静态 IP」 | 那是 WAN 上网方式，不是 LAN | 去「高级设置 → 局域网设置」 |
| 局域网设置里 LAN IP 是灰的 | 路由器处于中继模式，或固件锁定 | 恢复出厂选路由模式；仍不行见 2.9 |
| 型号确实没有 LAN IP 选项 | 少数型号固件不开放 | 见 2.9 的替代方案 |

### 2.9 如果型号确实改不了 LAN IP

先确认不是操作问题：`高级设置 → 局域网设置`，第一项就是「局域网 IP 地址」，
默认 `192.168.31.1`，可以直接改。

确认方法：登录管理页后，直接访问 **`http://192.168.31.1/cgi-bin/luci/;stok=/locale?form=lan`**
（部分固件可直接打开 LAN 设置页）。打不开或字段灰掉，说明该固件不开放。

**替代方案（按推荐顺序）**：

1. **换一台能做 LAN IP 设置的路由器**——最省事，任何 50 元左右的家用路由器都行，
   只要满足「2.4G + WAN/LAN 口 + 能改 LAN IP + 能设 WPA2 密码」。
2. **刷固件**：部分小米型号可刷 OpenWrt/Padavan，能自由设 LAN IP。
   有风险，不熟悉别碰。
3. **换一款同型号的旧固件**：小米路由器历史固件里早期版本 LAN IP 可改，
   新版本有的被锁。可去小米官网下载旧版固件降级，但同样有风险。

> ⚠️ **不要用「Wi-Fi 名称/密码能改就凑合」的思路**：
> 裁判系统主控固件里服务器地址是写死的 `192.168.1.2`，
> 局域网不在 `192.168.1.x`，主控永远找不到服务器，这一环绕不过去。

## 三、外网怎么解决（引擎必须联网）

官方原文：“当前版本赛事引擎裁判端**需要外部网络支持**”，启动时要求：
1. 关闭本机防火墙
2. 通过“本地 IP 配置测试”
3. 通过“外网连接测试”
4. 登录 DJI 会员账号

### 方案 A：路由器接外网（官方方案 1）

外网线插路由器 WAN 口 → PC-A 用网线接 LAN① → 全屋设备都能上网。
最简单，**优先用这个**。

### 方案 B：PC-A 双网卡（官方方案 2，没有外网线时用）

PC-A 的**有线网卡**接路由器 LAN（`192.168.1.2`），**Wi-Fi** 连校园网/手机热点上外网。

官方特别提醒：连了局域网后如果外网不通，要调整**网卡跃点数**：

1. 网络适配器 → 局域网网卡 → 属性 → IPv4 → **高级**
2. 取消勾选“自动跃点”
3. **局域网网卡接口跃点数设为 `20`**
4. **外网网卡（Wi-Fi）接口跃点数设为 `10`**
5. 确定保存

> 跃点数越小优先级越高。外网 10 < 局域网 20，保证默认走外网，同时局域网仍然可达。

```cmd
netstat -ano | findstr :3333
```

应为 `0.0.0.0:3333` 或 `192.168.12.1:3333` 的 LISTENING。

### 第三步：机器人上电，确认主控连上

1. 机器人裁判系统主控上电

```cmd
arp -a
```

应能看到 `192.168.1.x` 的条目（主控拿到的 DHCP 地址）。
也可以在路由器管理页 → **设备管理/终端设备**，看到多了一台设备。

4. 选手端界面应显示机器人**在线、血量正常**

### 第四步：PC-B 启动自定义客户端

1. 双击 **`luojiamaster.exe`**
2. 登录填 **`192.168.12.1:3333`**（协议规定地址）
3. **机器人 ID 与选手端选的一致**
4. 点登录
5. 进入后按 **`Esc`** 进比赛模式

## 十一、两台车 + 多台电脑 + 队友视角：上实车的现场部署

> 2026-11-02。这是**两台自定义客户端互看第一视角**（2027 赛季）的现场操作手册。
> 功能原理、线格式、判据解释在
> [`档案/阶段6-队友视角-互联-2026-11-02.md`](档案/阶段6-队友视角-互联-2026-11-02.md)；
> 本文只讲「怎么接、怎么设、按什么顺序开、坏了怎么查」。
>
> **电脑数量可以少一台**：官方赛场上「裁判端」和「官方端」是分开的两台（共 5 台），
> 自己练的时候引擎和其中一台选手端放在同一台电脑上就行（共 4 台）。
> 两种摆法下面都会写，接线和 IP 规则完全一样。

### 11.0 这套为什么能行（先看，避免多余担心）

| 担心 | 实际情况 |
|---|---|
| 队友网线会不会和官方链路抢 192.168.12.x？ | **不会。** 官方链路是「客户端 ↔ 自己那边的选手端」，物理上各自一根线；
队友网线是两台客户端之间的**另一块网卡**，走 `10.77.0.x`，三段互不相干 |
| 两个 `192.168.12.1` 会不会冲突？ | **不会。** 两个选手端各在自己的那根线上，两台客户端也都只连自己那根。
两根 12.x 网线**物理隔离**，广播互不可见 |
| 要不要给车刷固件？ | **不用。** 转发的是官方客户端已经收到的字节，车、VT03、VT13 都不参与 |
| 会不会影响官方图传和键鼠控制？ | **不会。** 队友链路是独立线程 + 有界队列，满了丢队友帧，主链路一帧都不让 |
| 不想要这个功能怎么办？ | 双击 `程序\关闭-队友视角.bat`（= `队友视角.ini` 里写 `peer=off`），下次启动完全回到没这个功能时：不出小窗、不占 47700、`K`/`L` 不注册（老版本 ini 里没有 `peer=off` 时照旧按默认 A 机启用） |

三段网络一张图（**共 3 个网段、6 根网线、5 台电脑**；4 台摆法少一根、少一台）：

```
【网段① 引擎/外网 192.168.1.0/24】

   路由器 192.168.1.1
        ├── PC-1  裁判端        主板 192.168.1.2     ← 引擎只认这个地址
        ├── PC-2  官方端·步兵   主板 DHCP/192.168.1.3
        ├── PC-3  官方端·英雄   主板 DHCP/192.168.1.4
        └── 两台机器人主控      2.4G Wi-Fi，DHCP 自动拿

【网段② 官方链路 —— 两条，物理上互相看不见】

   PC-2 ──USB 网卡 192.168.12.1 ──网线⑤── PC-4 网卡① 192.168.12.2
   PC-3 ──USB 网卡 192.168.12.1 ──网线⑥── PC-5 网卡① 192.168.12.2
         （两个 .1 同名不同网，因为两根线中间没有交换机）

【网段③ 队友链路 —— 一条，只连两台客户端】

   PC-4 ──网卡② 10.77.0.1 ══════网线⑦══════ 网卡② 10.77.0.2── PC-5

★ PC-4 / PC-5 的「网卡①」和「网卡②」必须是两块独立的网卡。
★ 网段①、②、③ 之间不要用交换机或路由器串起来。
★ 四台电脑时：PC-1 和 PC-2 合并成一台，主板既跑引擎（`192.168.1.2`）又跑步兵选手端。
```

### 11.1 角色与命名（先对上号，后面全用这套名字）

**官方赛场摆法（5 台）**：

| 代号 | 是谁 | 主要网卡 | 跑什么 |
|---|---|---|---|
| **PC-1** | 裁判端电脑 | 主板 `192.168.1.2` | `RoboMasterEngine.exe`（两份选手端共用一台引擎） |
| **PC-2** | 官方端 · 步兵 | 主板 `192.168.1.3`、USB 网卡 `192.168.12.1` | `RoboMasterClient.exe`（步兵）+ VT13 |
| **PC-3** | 官方端 · 英雄 | 主板 `192.168.1.4`、USB 网卡 `192.168.12.1` | `RoboMasterClient.exe`（英雄）+ VT13 |
| **PC-4** | 自定义客户端 · 步兵 | 网卡① `192.168.12.2`、网卡② `10.77.0.1` | `luojiamaster.exe` |
| **PC-5** | 自定义客户端 · 英雄 | 网卡① `192.168.12.2`、网卡② `10.77.0.2` | `luojiamaster.exe` |

**自己练的时候（4 台，少一台）**：把 PC-1 和 PC-2 并成一台。那台电脑的主板就是
`192.168.1.2`（引擎 + 步兵选手端同机），USB 网卡照样 `192.168.12.1`，
「客户端 ↔ 选手端」直连的规则一条不变。下面的步骤用 5 台的编号写，
4 台时看到 `PC-1` 和 `PC-2` 就当成同一台机器，**少接一根「PC-1 → 路由器」的网线**。

> **PC-2 和 PC-3 的主板 IP 不能都是 `192.168.1.2`。** 官方手册只规定了「裁判端主机」是 `.2`，
> 选手端主机走 DHCP 即可。要设静态就设 `.3` / `.4`，别撞 `.2`。
> 拿不准就**路由器 DHCP 自动获取**，这一层不影响自定义客户端。
>
> **4 台摆法里，PC-2 的主板必须正好是 `192.168.1.2`**（因为它是裁判端），
> PC-3 的主板走 DHCP 就行。

### 11.2 硬件清单

| 东西 | 数量（5 台摆法） | 说明 |
|---|---|---|
| 路由器（2.4G + WAN/LAN，能改 LAN IP，密码 `12345678`、WPA2） | 1 | 按本文第二、三节配好，主控靠它上线 |
| 网线 | 6 | PC-1↔路由器、PC-2↔路由器、PC-3↔路由器、PC-2↔PC-4、PC-3↔PC-5、PC-4↔PC-5（队友线）。**4 台摆法少一根** |
| **USB 网卡** | **6** | 见下表，**少一根队友链路就跑不起来** |
| VT13 接收端 | 2 | 分别插 PC-2、PC-3 |
| 交换机 | 0（路由器 LAN 口不够时 1 个） | 各台电脑按上面的拓扑各自直连，不会成环 |

> **路由器只有 2 个 LAN 口怎么办？** 小米这类家用路由器通常只有 2 个 LAN，
> 而这一层要接**三台电脑**（PC-1 引擎 + PC-2 + PC-3）。两个办法：
> ① 其中一台官方端用 Wi-Fi 连路由器（选手端连引擎只走 `192.168.1.x`，官方手册允许；
> 但**图传延迟会比有线差**，赛前务必试一次）；
> ② 加一个**小交换机**，只接在 `192.168.1.x` 这一层（PC-1 / PC-2 / PC-3 和路由器 LAN 都插它）。
> **千万别用它去并 `192.168.12.x` 或 `10.77.0.x`** —— 那两层必须各是一根直连，
> 否则两个 `192.168.12.1` 会撞进同一个广播域。也可以直接换一个 4 口以上 LAN 的路由器。

USB 网卡的分配（这是最容易少买的地方）：

| 用在哪 | 干嘛 | 数量 |
|---|---|---|
| PC-2（官方端步兵） | 给客户端 A 提供 `192.168.12.1` | 1 |
| PC-3（官方端英雄） | 给客户端 B 提供 `192.168.12.1` | 1 |
| PC-4（客户端步兵） | 接官方端 `192.168.12.2` | 1 |
| PC-4（客户端步兵） | **接队友网线 `10.77.0.1`** | 1 |
| PC-5（客户端英雄） | 接官方端 `192.168.12.2` | 1 |
| PC-5（客户端英雄） | **接队友网线 `10.77.0.2`** | 1 |

> PC-4 / PC-5 如果是笔记本、自带以太网口，可以少买 2 个；如果是只有 Wi-Fi 的轻薄本，
> **一台要两块 USB 网卡**。买之前先 `ipconfig /all` 数一下现有网口。
>
> **两台客户端的两根线绝对不能插在同一块网卡上**（比如用一个小交换机把「官方链路 + 队友链路」并到一起）：
> 那样 `192.168.12.x` 和 `10.77.0.x` 会落在同一个广播域，还会把两个 `192.168.12.1` 暴露给同一块网卡。

### 11.3 接线（按这个顺序插）

```
路由器 192.168.1.1（LAN① LAN② LAN③ 三个口，2.4G Wi-Fi 密码 12345678）
 ├─ LAN① ── PC-1 裁判端            主板 192.168.1.2        跑引擎
 ├─ LAN② ── PC-2 官方端·步兵       主板 DHCP（建议 1.3）    跑选手端 + VT13
 └─ LAN③ ── PC-3 官方端·英雄       主板 DHCP（建议 1.4）    跑选手端 + VT13
       （两台机器人主控不插线，连 2.4G Wi-Fi，自动拿 192.168.1.x）

网线⑤  PC-2 USB网卡 192.168.12.1 ────── PC-4 网卡① 192.168.12.2
网线⑥  PC-3 USB网卡 192.168.12.1 ────── PC-5 网卡① 192.168.12.2
网线⑦  PC-4 网卡② 10.77.0.1    ══════ PC-5 网卡② 10.77.0.2   ← 队友网线
```

> 路由器只有 2 个 LAN 口时，见 11.2 的两个办法（其中一台官方端走 Wi-Fi，或在
> `192.168.1.x` 这一层加个小交换机）。**别用交换机去并 12.x / 10.77.x 那两层。**

插线顺序（**先插网线，后开机**，Windows 才会稳定地把「网络 2 / 网络 3」排好）：

1. 路由器上电，PC-1 / PC-2 / PC-3 的主板各接一根 LAN 口
2. PC-2 插 USB 网卡 → 网线 → PC-4 的**网卡①**
3. PC-3 插 USB 网卡 → 网线 → PC-5 的**网卡①**
4. PC-4 插第二块 USB 网卡 → 网线 → PC-5 的第二块 USB 网卡（**网卡②对网卡②**）
5. VT13 接收端分别插 PC-2、PC-3 的 USB 口

> 插完再看 `ipconfig`，网卡名字会是「以太网」「以太网 2」「以太网 3」这种。
> **名字和用途的对应关系一定要记下来**，下面设 IP 时 `netsh` 要按名字指定。
> 建议直接在「网络连接」里重命名成 `官方链路` / `队友链路`，后面就不会搞混。
> 两块 USB 网卡长得一模一样，插反了不一定立刻报错——**宁可多花 30 秒认名字，也别猜**。

**怎么确认自己没插反？** 插好、设完 IP 之后，在两台客户端上各跑一次 `ipconfig /all`，
对着每块网卡的「描述」（USB 网卡的型号名）和 IPv4 地址看：

- 官方链路那块网卡：对端是**选手端**（PC-2 / PC-3），`ping 192.168.12.1` 通
- 队友链路那块网卡：对端是**另一台客户端**（PC-5 / PC-4），`ping 10.77.0.x` 通

两个方向只有一个通 → 两块网卡的 IP 设反了（官方那块填了 `10.77.0.x`，或反过来）。
在「网络连接 → 属性 → IPv4」里把「官方链路」那块改成 `192.168.12.2`、
「队友链路」那块改成 `10.77.0.x` 即可，**不需要拔线重插**。

### 11.4 IP 设置：逐个网卡照着填

| 电脑 | 网卡 | IP | 掩码 | 网关 | DNS | 怎么设 |
|---|---|---|---|---|---|---|
| PC-1 | 主板 | `192.168.1.2` | `255.255.255.0` | `192.168.1.1` | 留空 | 手动 |
| PC-2 | 主板 | DHCP 自动获取 | | | | **别动** |
| PC-2 | USB 网卡 | `192.168.12.1` | `255.255.255.0` | **留空** | 留空 | 手动 |
| PC-3 | 主板 | DHCP 自动获取 | | | | **别动** |
| PC-3 | USB 网卡 | `192.168.12.1` | `255.255.255.0` | **留空** | 留空 | 手动 |
| PC-4 | 网卡① | `192.168.12.2` | `255.255.255.0` | **留空** | 留空 | 手动 |
| PC-4 | 网卡② | `10.77.0.1` | `255.255.255.0` | **留空** | 留空 | 手动 / 脚本 |
| PC-5 | 网卡① | `192.168.12.2` | `255.255.255.0` | **留空** | 留空 | 手动 |
| PC-5 | 网卡② | `10.77.0.2` | `255.255.255.0` | **留空** | 留空 | 手动 / 脚本 |

> **网关一律留空**（除了 PC-1 的主板）。原因是不能抢默认路由：PC-1 要靠路由器上网做外网测试，
> PC-2/PC-3 的主板 DHCP 已经给了默认路由，其它几块网卡再填网关就会打架。
>
> **PC-2 和 PC-3 的主板千万别设成 `192.168.1.2`** —— 那是 PC-1 的地址。
> 官方手册里 `.2` 是**裁判端**的，选手端走 DHCP 就行。

队友网线那两块网卡，`程序\` 里有现成脚本（**右键 → 以管理员身份运行**）：

```
设置-队友网线.bat               PC-C → 把接队友线的网卡设成 10.77.0.1
设置-队友网线.bat B             PC-D → 设成 10.77.0.2
设置-队友网线.bat B "以太网 3"   网卡有歧义时手动指定名字
```

> 脚本不再写死网卡名：它自动排除「已经不是 `192.168.12.x` 的官方链路网卡」和
> 「有默认网关的上网网卡」，只剩一块时直接设。剩下不止一块会报 `[失败]` 并列出候选，
> 带上名字再跑一次即可。
>
> **顺序很重要**：先插官方网线、把官方网卡设成 `192.168.12.2` 并 ping 通 `12.1`，
> **再**插队友网线跑这个脚本。先插队友线的话脚本分不清两块网卡，
> 可能把 `10.77.0.1` 写到官方网卡上，官方链路就断了。
> 也可以完全不用脚本，在「网络连接 → 属性 → IPv4」里手填，一条都不差。
>
> **网卡①（`192.168.12.2`）必须手填**，脚本不管它：各台机器的网卡名都不一样，
> 脚本写死名字反而更容易设错。

**PC-4 / PC-5 都要能同时通两条链路**，所以两台都必须有两块在用中的网卡。
只插了队友网线、没插官方链路的话，客户端连不上选手端，主画面就是黑的。

### 11.5 验证（设完 IP 立刻做，别急着开客户端）

在 **PC-4** 上依次执行：

```cmd
ipconfig
```

应该看到**两块**在用中的网卡，地址分别是 `192.168.12.2` 和 `10.77.0.1`。
看到 `媒体已断开` 或者地址是 `169.254.x.x`，说明那根线/那块网卡没通。

```cmd
ping 192.168.12.1
ping 10.77.0.2
```

两条都要 `来自 ... 的回复`、0% 丢失。**第二条不通，队友画面一定不会出来**，
不用往下走，先查线、查网卡名、查 IP。

在 **PC-5** 上对称地做：

```cmd
ipconfig
ping 192.168.12.1
ping 10.77.0.1
```

> 规则只有一句：**客户端 ping 自己那根线上的 `.1`，ping 不过去就是这一段的问题**。
> PC-4 的 `192.168.12.1` 在 PC-2，PC-5 的 `192.168.12.1` 在 PC-3 —— 两个 `.1` 物理隔离，各通各的。

**上面这一整组检查有现成脚本**：在 PC-4 / PC-5 上双击 `程序\现场自检-四台电脑.bat`（**不需要管理员**），
它会依次检查两块网卡、两条 ping、两条防火墙规则、47700 监听、exe 的 MD5，
每一项打 `[OK]` / `[!!]` / `[--]`，最后给结论。**`[--]` 是「看情况」，`[!!]` 才是硬问题。**

### 11.6 防火墙：两台客户端各跑一次脚本（**官方端不跑**）

PC-4 / PC-5 上要开的入站端口有两个，**一个脚本一起搞定**：

右键 `程序\防火墙-放行客户端端口.bat` → **以管理员身份运行**。

```
[完成] 已放行入站 TCP 47700
[完成] 已放行入站 UDP 3334
```

重复运行会显示「跳过 … 规则已存在」，正常。确认：

```cmd
netsh advfirewall firewall show rule name="RM Teammate Video 47700"
netsh advfirewall firewall show rule name="RM Client UDP 3334"
```

为什么要这两条：

| 端口 | 谁往这里发 | 漏了会怎样 |
|---|---|---|
| `TCP 47700` | 队友那台客户端（队友视频） | 右上角小窗一直「未连接」/ 只有一边显示「已连队友」 |
| `UDP 3334` | 自己那边的官方选手端（官方图传） | **登录成功，但主画面永远是黑的** |

`3333/tcp` **不用放行**：MQTT 是客户端**主动连**选手端的，Windows 防火墙对已建立连接的
返回流量本来就是放行的。

> **能整机关防火墙就整机关**（本文第六节），那种情况下这个脚本可以跳过 —— 但**别只关一边**。
> PC-2 / PC-3 **不要跑这个脚本**：官方手册要求官方端整机关防火墙，
> 在选手端上放行端口会让引擎判定不合规。

### 11.7 启动顺序（严格照这个来）

顺序的原则：**引擎 → 主控 → 官方选手端 → 自定义客户端**。每步确认了再下一步。

### 第 1 步 · PC-1：引擎

1. 启动 `RoboMasterEngine.exe`
2. 「本地 IP 配置测试」「外网连接测试」两项都通过
3. 登录 DJI 账号 →「开始使用」
4. 确认：`netstat -ano | findstr :15861` 有 LISTENING

### 第 2 步 · 机器人上电

1. 步兵、英雄两台主控各自上电，**自动连路由器的 2.4G Wi-Fi**
2. PC-1 上 `arp -a` 能看到两个 `192.168.1.x`
3. 先在引擎里确认两台机器人都**在线**

### 第 3 步 · PC-2 / PC-3：官方选手端

两台各做一遍，**步兵选步兵、英雄选英雄，别选错**：

1. 启动 `RoboMasterClient.exe`（**版本 ≥ 12.0.0.213**）
2. 服务器填 `192.168.1.2`（引擎所在机器）
3. 登录 → 选队伍 → 选机器人（**PC-2 选步兵、PC-3 选英雄**）
4. 确认**官方图传画面正常**（这是硬性前提，不然后面客户端也没图）
5. 按 `P` → **键鼠控制来源 → 自定义客户端**
6. 确认：`netstat -ano | findstr :3333` 有 LISTENING

> **这一条最容易翻车：两个选手端的机器人 ID 必须和各自客户端选的一致。**
> PC-2 选的是 3 号步兵，PC-4 就必须选 3 号步兵；PC-3 选英雄，PC-5 就选英雄。

### 第 4 步 · PC-4 / PC-5：自定义客户端

**队友视角现在是一键的：双击 `程序\luojiamaster.exe` 就有，不需要放任何文件。**

- **PC-4（步兵位）**：默认就是 A 机（找 `10.77.0.2:47700`），标题条上会标 `[默认A]`。
- **PC-5（英雄位）**：打开后点一下小窗标题条上的 `[默认A]`，变成 `[B]` 就切好了
  （找 `10.77.0.1:47700`），会自动写回 exe 旁边的 `队友视角.ini`，以后打开都是 B。

> 想「一开机就是 B 机、不用点」：双击 `程序\固定-B机.bat`（PC-4 用 `固定-A机.bat`）。
> 它只是把 `队友视角-B机.ini` 复制成 `队友视角.ini`，内容就一行 `role=B`。

> **小窗标题条怎么读**：`未连接` / `已连队友` / `队友已连入` / `双向已连`。
> 小窗里没画面时会直接写出「本机 A 机，找 10.77.0.2」这类提示，该连谁一目了然。
> `K` / `L` 不生效只有在 `队友视角.ini` 里写了 `peer=off` 时才会出现——那是你主动关掉的。
> 参数确认：看 `程序\logs\<最新时间戳>\robogo.log`，三种来源各有一行——
> `队友视角使用内置默认（A 机）：peer=10.77.0.2:47700 listen=47700` /
> `队友视角参数来自 队友视角.ini：...` / `队友视角已在 队友视角.ini 里关闭（peer=off）`。
> 打不开 ini（被占用/权限）时还会多一行 WARN，本次按默认 A 机走，不影响使用。

> 老办法仍然有效（调试/临时覆盖用）：命令行传 `--teammate-peer 10.77.0.2:47700 --teammate-listen 47700`
> 时**命令行优先**，`队友视角.ini` 的地址被忽略（只取 role 显示）。本机双实例测试用的
> `启动-本地测试-A/B.bat` 就属于这种情况——那时两台是 `127.0.0.1`，不跟角色走。

两个客户端里各做：

1. 登录页 MQTT 服务器填 **`192.168.12.1:3333`**（**两台都一样**，各自连自己那条线）
2. 选队伍 → 选机器人（**PC-4 选步兵、PC-5 选英雄**，和各自选手端保持一致）
3. 点登录 → 进去后按 **`Esc`** 进比赛模式

> 两台客户端的**机器人 ID 不需要互不相同**（它们在两条独立的 MQTT 会话里），
> 只要各自和自己那边的选手端对得上就行。

> **登录时如果提示「连接失败，重试中」，先分清是哪一条链路。**
> MQTT 走的是网卡①（`192.168.12.2` → `192.168.12.1`），和队友网线没有关系；
> 队友链路的死活只看**右上角小窗标题条**。两件事分开查，别一看到红字就去拔队友网线。

### 第 5 步 · 确认队友画面

两台客户端的**右上角**都应该出现「队友视角」小窗：

- 标题条：**绿色 + `双向已连`**
- 画面：**对方的车**的第一视角（PC-4 看到英雄视角，PC-5 看到步兵视角）
- 日志「队友探针」每秒一行，`发` / `收` / `解` 都在涨、`错误=0`

按键（**先把鼠标点进要操作的那个窗口**）：

| 键 | 作用 |
|---|---|
| `K` | 折叠 / 展开小窗（折叠后只剩一条状态条） |
| `L` | 队友画面接管主画面，再按一次恢复 |
| 滚轮 | **只在 `L` 模式下**生效，1x~4x 中心放大 |

> 冲突提醒：`H` 仍然管**本机**的主/副画面，`I` 管**本机**官方画面翻转，
> 按键都只对当前窗口生效。**不要按 CTRL** —— 那是整车复位。

### 11.8 判读表（出问题时按这个查，一次只改一个变量）

### 队友链路

|---|---|---|

## 十之一、旧版三机方案一页速查（打印版）

```

  路由器 LAN = 192.168.1.1，开 DHCP，2.4G，密码 12345678，WPA2-PSK
  裁判端主机 = 192.168.1.2，必须网线接 LAN
  自定义客户端链路 = 192.168.12.1（服务器）/ 192.168.12.2（客户端）
```

## 十二、四台电脑标准摆法（两台车 + 两台官方端 + 两台客户端）

> 2026-11-02 定稿。这是 CH 实际要复现的摆法：**两台车、两台官方端电脑、两台自定义客户端电脑。
> 两台客户端之间一根专用网线（队友视角）；每台客户端和它对应的官方端各一根网线（官方链路）。**
>
> 和第十一节的 5 台摆法相比：少了单独的裁判端电脑（引擎和其中一台官方端同机），
> **但两台官方端都在线跑，不是离线模式**。第十一节里所有接线细节、IP 规则、判据依然有效，
> 本节只写这套摆法下「哪根线插哪、谁填什么 IP、按什么顺序开」。

### 12.1 角色表（先对号，后面全用这名字）

| 代号 | 是谁 | 跑什么 | 有线口需要 |
|---|---|---|---|
| **PC-A** | 官方端 · 步兵 | 赛事引擎（裁判端）**+** 步兵官方选手端 + 步兵 VT13 | 主板 `1.x` + USB① `12.1` |
| **PC-B** | 官方端 · 英雄 | 英雄官方选手端 + 英雄 VT13 | 主板 `1.x` + USB① `12.1` |
| **PC-C** | 自定义客户端 · 步兵 | `luojiamaster.exe`（默认 A 机） | 主板 `12.2` + USB② `10.77.0.1` |
| **PC-D** | 自定义客户端 · 英雄 | `luojiamaster.exe`（点一下变 B 机） | 主板 `12.2` + USB② `10.77.0.2` |

> **引擎只认 `192.168.1.2`**，所以它所在那台（PC-A）必须**网线**接路由器 LAN
> （官方原文：请勿使用无线方式连接裁判端主机与无线路由器）。PC-B 接路由器可以走网线，也可以走 Wi-Fi。

### 12.2 接线图（四根网线 + 路由器两根）

```
【网段① 192.168.1.0/24 —— 引擎 / 主控 / 外网】
   小米路由器 192.168.1.1（LAN IP 必须改成这个，见 12.5）
     ├─ LAN① ── PC-A 主板 192.168.1.2     引擎（裁判端）+ 步兵选手端
     ├─ LAN② ── PC-B 主板 DHCP/1.3        英雄选手端
     └─ 2.4G Wi-Fi ── 步兵主控 + 英雄主控（各自 DHCP 拿 1.x）

【网段② 官方链路 —— 两条，物理上互相看不见】
   PC-A USB① 192.168.12.1 ──网线①── PC-C 主板 192.168.12.2
   PC-B USB① 192.168.12.1 ──网线②── PC-D 主板 192.168.12.2

【网段③ 队友链路 —— 一条，只连两台客户端】
   PC-C USB② 10.77.0.1 ══网线③══ PC-D USB② 10.77.0.2
```

**一句话记法**：客户端的两块网卡，一块朝「自己那台官方端」（`12.2`），一块朝「另一台客户端」（`10.77.0.x`）；
官方端的 USB 网卡一律 `12.1`，两台官方端的 `12.1` 因为中间没有交换机，可以同名。

> **四块网卡型号可能一模一样**（都是 USB 转网口），Windows 会按插入顺序叫「以太网 2 / 以太网 3」，
> 插错一个口就可能把 `10.77.0.1` 写到官方网卡上。**认线的办法不是看名字，是看 IP**：
> 一块是 `192.168.12.2`，一块是 `10.77.0.x`。设完一定要 `ipconfig` 看一眼。

> **两台客户端的 `12.2` 也同名**，原因一样：两条官方链路互相隔离。
> **但队友线必须独立**：它把两台客户端连在同一个 `10.77.0.x` 广播域里，谁都不能再用这块网卡跑官方链路。

### 12.3 IP 清单（照着填，只填这几项）

| 电脑 | 网卡 | IP | 掩码 | 网关 | DNS | 怎么设 |
|---|---|---|---|---|---|---|
| PC-A | 主板 | `192.168.1.2` | 255.255.255.0 | `192.168.1.1` | 空 | 手填 |
| PC-A | USB① 官方链路 | `192.168.12.1` | 255.255.255.0 | **空** | 空 | 手填 |
| PC-B | 主板 | DHCP（建议 `192.168.1.3`） | 自动 | 自动 | 自动 | **别动** |
| PC-B | USB① 官方链路 | `192.168.12.1` | 255.255.255.0 | **空** | 空 | 手填 |
| PC-C | 主板 官方链路 | `192.168.12.2` | 255.255.255.0 | **空** | 空 | 手填 |
| PC-C | USB② 队友链路 | `10.77.0.1` | 255.255.255.0 | **空** | 空 | 脚本 |
| PC-D | 主板 官方链路 | `192.168.12.2` | 255.255.255.0 | **空** | 空 | 手填 |
| PC-D | USB② 队友链路 | `10.77.0.2` | 255.255.255.0 | **空** | 空 | 脚本 |

规则一句话：**只有 PC-A 主板填网关，其余全部留空。** 其它网卡填了网关就是抢默认路由，
轻则引擎外网测试不过，重则两台官方端都上不了网。

队友线那两块网卡用脚本（**右键 → 以管理员身份运行**）：

```
PC-C:  程序\设置-队友网线.bat                → 10.77.0.1
PC-D:  程序\设置-队友网线.bat B              → 10.77.0.2
```

脚本会自动跳过「已经是 `192.168.12.x`」的官方链路网卡和有默认网关的上网网卡，
免得把官方链路设错。**两块 USB 网卡一模一样，这一步最容易插反。**

### 12.4 硬件预算（别少买，也别买错）

每台电脑 2 个有线口（主板 + 1 块 USB 网卡），合计 **4 块 USB 网卡**：

| 电脑 | 主板口 | USB 网卡 | 备注 |
|---|---|---|---|
| PC-A | 路由器 `1.2` | **`12.1`** → PC-C | 还要再插 VT13 |
| PC-B | 路由器 `1.x` | **`12.1`** → PC-D | 只有 1 块 USB 时：主板接客户端 `12.1`，Wi-Fi 连路由器 |
| PC-C | `12.2` → PC-A | **`10.77.0.1`** → PC-D | 正好 1 块 USB |
| PC-D | `12.2` → PC-B | **`10.77.0.2`** → PC-C | 正好 1 块 USB |

> CH 现在确认的是「两块新 USB 网卡都到货」——那两块正好给 PC-C / PC-D 当队友线。
> 两台官方端各需要一块 USB 网卡跑 `12.1`：PC-A 原来那块就是，PC-B 如果没有，
> 用「主板接客户端 + Wi-Fi 连路由器」也能跑（英雄选手端走 Wi-Fi 到引擎，延迟略高，自己练够用）。
>
> **VT13 接收端**：PC-A 插步兵那套、PC-B 插英雄那套。VT13 只是把无线图传转成 USB，
> 不参与 IP 配置，插上装好驱动即可。

### 12.5 路由器：能不能用先判定

引擎登录前要求「本地 IP 配置测试」「外网连接测试」两项通过；主控固件写死服务器地址 `192.168.1.2`，
所以路由器 LAN 必须是 `192.168.1.x`。

1. 浏览器打开 `192.168.1.1`（打不开就试 `http://192.168.31.1`）
2. 找 **「高级设置 → 局域网设置」**（或「LAN 设置」「DHCP 服务」）
3. 看「局域网 IP 地址」能不能改

| 情况 | 处理 |
|---|---|
| 现在 `192.168.31.1`，能改 | 改成 `192.168.1.1`，掩码 `255.255.255.0`，DHCP 保持开启，保存后等 1~2 分钟重启；在 PC-A 跑 `ipconfig /release` + `ipconfig /renew` 确认网关变成 `192.168.1.1` |
| 已经是 `192.168.1.1` | 跳过，继续 12.6（四级验收） |
| 找不到 LAN IP 或改了不生效 | **换一台能改 LAN IP 的路由器**（最省事）。绕不过去：主控必须拿到 `1.x` 才能找到引擎 |

**外网**：最省事是路由器 WAN 口接一根能上网的线。没有的话，让 PC-A 另开 Wi-Fi 连手机热点/校园网，
再按官方要求调跃点数：**局域网网卡（主板 1.2）跃点数 20，外网网卡（Wi-Fi）跃点数 10**。
（网络适配器 → 网卡 → 属性 → IPv4 → 高级 → 取消「自动跃点」→ 填接口跃点数。）

### 12.6 次第验收：四级，每级单独能过

**不要一次全开再 debug。** 每级通过再进下一级，出问题时只可能在新加的那一层。

| 级别 | 目标 | 需要 | 判据 |
|---|---|---|---|
| **L1** | 两台客户端各自登录、看到本车官方图传 | PC-A、PC-B、PC-C、PC-D + 两根官方链路网线 + 两台车图传 | 两台客户端主画面都是自己那台车的第一视角 |
| **L2** | 队友视角双向连通 | L1 + 两根 USB 网卡 + 队友网线 | 两边小窗「双向已连」，画面是对方的车 |
| **L3** | 裁判系统在线 | L2 + 路由器改成 `1.x` + 引擎 + 两台主控在线 | 引擎两项测试通过，客户端能看到血量/比赛时间 |
| **L4** | 工业相机第二视角 | L3 + Jetson 自瞄（0x0310） | 左侧「本车视频」能辨认出画面 |

### 12.7 启动顺序（严格照做）

#### 第 1 步 · 接线、设 IP、防火墙

1. 按 12.2 插四根网线；**先插官方那两根、设好 `192.168.12.2` 并 ping 通 `12.1`，
   再插队友网线**。顺序反了的话，`设置-队友网线.bat` 会分不清两块网卡，
   可能把 `10.77.0.1` 写到官方网卡上（脚本靠「已经是 `12.x`」来认官方网卡）。
2. 按 12.3 设 IP；`ipconfig` 核对每块网卡的地址
3. PC-C、PC-D 各跑一次 `程序\防火墙-放行客户端端口.bat`（管理员）：
   放行入站 `TCP 47700`（队友视频）+ `UDP 3334`（官方图传）
4. 验证（两台客户端各跑一次）：`程序\现场自检-四台电脑.bat`（不需要管理员）
   - **PC-C**：`ping 192.168.12.1`（自己那台官方端）、`ping 10.77.0.2`（PC-D）都要通
   - **PC-D**：`ping 192.168.12.1`（自己那台官方端）、`ping 10.77.0.1`（PC-C）都要通
   - `ping 192.168.1.1` / `192.168.1.2` 在离线练习时可以不通（脚本打 `[--]`，不是错）
   - 脚本里**只有 `[!!]` 是硬问题**；`[--]` 是「看情况」

#### 第 2 步 · PC-A：引擎

1. 启动 `RoboMasterEngine.exe`
2. 「本地 IP 配置测试」「外网连接测试」**两项都通过** → 登录 DJI 账号 → 「开始使用」
3. 判据：`netstat -ano | findstr :15861` 有 `LISTENING`

#### 第 3 步 · 两台车：主控上电

1. 步兵、英雄主控各自上电，自动连路由器 2.4G Wi-Fi
2. PC-A 上 `arp -a` 能看到两个 `192.168.1.x`
3. 引擎里两台机器人都**在线**

#### 第 4 步 · PC-A、PC-B：官方选手端

两台各做一遍，**PC-A 选步兵、PC-B 选英雄，别选反**：

1. 启动 `RoboMasterClient.exe`（**版本 ≥ 12.0.0.213**，旧版没有自定义客户端能力）
2. 服务器填 `192.168.1.2` → 登录 → 选队伍 → 选机器人
3. **确认官方图传画面正常**（硬性前提：选手端自己没画面就不会往外推流）
4. 按 `P` → **键鼠控制来源 → 自定义客户端**
5. 判据：`netstat -ano | findstr :3333` 有 `LISTENING`
6. VT13：PC-A 插步兵那套、PC-B 插英雄那套

> **两个选手端的机器人 ID 不能反**：PC-A 选手端选的机器人 = PC-C 客户端要登录的机器人；
> PC-B 选手端选的机器人 = PC-D 客户端要登录的机器人。

#### 第 5 步 · PC-C、PC-D：自定义客户端

**队友视角是一键的：双击 `程序\luojiamaster.exe` 就有，不放任何文件。**

1. 登录页 MQTT 服务器填 **`192.168.12.1:3333`**（**两台都填这个**，各自走自己那根官方链路）
2. 选队伍 → 选机器人（**PC-C 选步兵、PC-D 选英雄**，和各自官方端选手端一致）
3. 点登录 → 进去按 **`Esc`** 进比赛模式
4. **PC-C**：小窗标题条是 `[默认A]`（找 `10.77.0.2`）——不用动
5. **PC-D**：点一下小窗标题条上的 `[默认A]` → 变成 `[B]`（找 `10.77.0.1`），
   自动写回 exe 旁的 `队友视角.ini`，以后打开都是 B
6. 判据：**两边小窗都显示「双向已连」**，画面是对方的车

#### 第 6 步 · 确认三块画面

| 画面 | 位置 | 来源 |
|---|---|---|
| 主画面（本车第一视角） | 正中 | 自己那台官方端选手端 → UDP 3334 |
| 本车视频（工业相机第二视角） | 左下小块 | Jetson → 0x0310 → 图传 → 选手端 → 客户端 |
| 队友视角 | 右上小窗 | 两台客户端之间的 `10.77` 网线 |

### 12.8 判读表（一次只改一个变量）

| 现象 | 先查 |
|---|---|
| 客户端登录一直「连接失败，重试中」 | `ping 192.168.12.1`；`12.1` 是不是在**自己那台**官方端上；选手端 ≥ 12.0.0.213；PC-A/PC-B 防火墙 3333 |
| 登录上了但主画面黑 | 自己那台选手端有没有图传画面；机器人 ID 是否和选手端一致；`UDP 3334` 是否被防火墙拦 |
| 有画面但车不动 | 选手端 `P` 面板没切「自定义客户端」；没按 `Esc`；比赛阶段不允许操作 |
| 小窗两边都「未连接」 | `ping 10.77.0.x` 不通 → 网线/网卡/IP（12.3）；通 → 防火墙 47700 |
| 一边「已连队友」一边「未连接」 | 只通一半：查连不进来那台的 47700 监听和防火墙 |
| 「双向已连」但没画面 | 自己那台官方图传是否正常？对方图传黑，你这边就没像素可显示 |
| 画面冻住 > 5 s | 正常：链路标「已断」但保留最后一帧，恢复后自动接上 |
| 左上「本车视频」一直等待 | Jetson 上 `[VideoSender]` 统计：成帧不涨、**超限丢弃**涨 → 尺寸/码率问题，别动客户端 |
