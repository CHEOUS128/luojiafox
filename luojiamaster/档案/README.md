## 唯一还悬着的一跳

**STM32 USART6 → VT03 → 无线** 这一跳至今**没有干净的对照实验**。
已经排除的：带宽、键鼠输入、云台指令、客户端渲染、客户端解包/解码。
CH 现场体感：开小陀螺时画面几乎不断 —— 与「通道对静止数据流不友好」这类**可能性**一致，
但**没有证据**。要证实只能烧带 `VideoForward_Debug` 的固件，读 `frames` vs `forwarded`。
详见基线文档第六节第 6、7 条。
