## 自定义客户端使用方法

一、安装软件

1. 安装 Vulkan SDK：https://vulkan.lunarg.com
2. 安装 Ninja：sudo apt install ninja-build

二、编译代码

```sh
cmake --preset release
cmake --build --preset release
```

三、运行程序

```sh
./build/release/RoboGo
```
