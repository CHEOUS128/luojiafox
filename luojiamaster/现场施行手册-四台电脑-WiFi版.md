# 四台电脑 · WiFi 版 现场操作手册

> 2026-11-03 定稿。**照着点鼠标就行**，每一步都写到「右键哪个图标、点哪个按钮、填什么数字」。
>
> 本手册对应的硬件前提（四台笔记本都一样）：
> **每台都有 1 个自带 RJ45 网口 + 1 块无线网卡 + 若干 USB 口。**

---

## 0. 一句话说清楚这套摆法

**四台电脑 + 两台机器人的主控，全部用无线网卡连同一个 WiFi。**
电脑之间另走两条直连网线（每台笔记本的自带网口对自带网口），
两台客户端之间再走一根 USB 转网卡的网线。

```
                        ┌──────────────────────────┐
                        │ WiFi 路由器（赛事服务器）│
                        │ LAN 192.168.1.1          │
                        └───┬───┬───┬───┬───┬───┬──┘
             无线  ┌───────┘   │   │   │   │   └───────┐  无线
                   │           │   │   │   │           │
              ┌────┴────┐ ┌────┴───┴───┴───┴────┐ ┌────┴────┐
              │  PC-A   │ │  步兵主控   英雄主控 │ │  PC-B   │
              │ 官方端  │ │  （两台机器人）      │ │ 官方端  │
              │ + 引擎  │ └──────────────────────┘ │         │
              └─┬─────┬─┘                          └─┬─────┬─┘
        自带网口│     │USB                         自带网口│     │USB
       12.1     │     │手机共享                    12.1    │     │VT13
      ┌─────────┘     │（外网）                  ┌─────────┘
      │               │                          │
  ┌───┴─────┐         │                      ┌───┴─────┐
  │  PC-C   │◄────────┘                      │  PC-D   │
  │ 客户端  │  USB转网卡 + 一根网线（队友线） │ 客户端  │
  │ 12.2    ├─────────────────────────────────┤ 12.2    │
  └─────────┘        10.77.0.1 ↔ 10.77.0.2    └─────────┘
```

**五条链路：**

| # | 链路 | 谁和谁 | 走哪块网卡 | 网段 |
|---|---|---|---|---|
| ① | 赛事局域网 | 四台电脑 + 两台主控 ↔ 路由器 | **每台的无线网卡（Wi-Fi）** | `192.168.1.0/24` |
| ② | 引擎 | PC-A 上的引擎 ↔ 主控 | 跟 ① 同一条 | `192.168.1.2` |
| ③ | 外网 | PC-A ↔ 互联网 | **手机 USB 共享**（一根数据线） | 自动 |
| ④ | 官方链路 ×2 | A↔C、B↔D | **两台笔记本的自带 RJ45 网口 + 一根网线** | `192.168.12.0/24` |
| ⑤ | 队友链路 | C ↔ D | **两块 USB 转 RJ45 网卡 + 一根网线** | `10.77.0.0/24` |

> ④ 的两根线中间没有交换机、互不可见，所以「两个 `192.168.12.1`、两个 `192.168.12.2`」同时存在不冲突。

## 1. 每台机器的网络账（先看懂这张表）

| 机器 | 网卡 | 连什么 | IP | 掩码 | 网关 | DNS |
|---|---|---|---|---|---|---|
| **PC-A**（官方端·步兵，跑引擎） | **无线网卡** | WiFi 路由器 | `192.168.1.2` | `255.255.255.0` | **留空** | **留空** |
| | **自带 RJ45** | 网线 → PC-C 自带 RJ45 | `192.168.12.1` | `255.255.255.0` | **留空** | **留空** |
| | **手机 USB 共享** | 手机（外网） | 自动 | 自动 | 自动 | 自动 |
| **PC-B**（官方端·英雄） | **无线网卡** | WiFi 路由器 | 自动（DHCP） | 自动 | 自动 | 自动 |
| | **自带 RJ45** | 网线 → PC-D 自带 RJ45 | `192.168.12.1` | `255.255.255.0` | **留空** | **留空** |
| **PC-C**（客户端·步兵） | **无线网卡** | WiFi 路由器 | 自动（DHCP） | 自动 | 自动 | 自动 |
| | **自带 RJ45** | 网线 → PC-A 自带 RJ45 | `192.168.12.2` | `255.255.255.0` | **留空** | **留空** |
| | **USB 转 RJ45** | 网线 → PC-D 的 USB 转 RJ45 | `10.77.0.1` | `255.255.255.0` | **留空** | **留空** |
| **PC-D**（客户端·英雄） | **无线网卡** | WiFi 路由器 | 自动（DHCP） | 自动 | 自动 | 自动 |
| | **自带 RJ45** | 网线 → PC-B 自带 RJ45 | `192.168.12.2` | `255.255.255.0` | **留空** | **留空** |
| | **USB 转 RJ45** | 网线 → PC-C 的 USB 转 RJ45 | `10.77.0.2` | `255.255.255.0` | **留空** | **留空** |

> 四台电脑都连 WiFi。C、D 连 WiFi 只是为了「现场能上网查东西 / 能 `git pull`」，
> 它们的所有业务流量都走那两根网线，**WiFi 那块保持默认自动获取就行，一个字都不用改**。

**三条铁律：**

1. **只有「手机 USB 共享」那块网卡填网关，其余全部留空。**
   网关留空 = 不抢默认路由 = 引擎的「外网连接测试」能过。
2. **同一块网卡上不能有两个网段。** 每块网卡只配一个 IP。
3. **C、D 的自带网口只能接自己那台官方端，不能接路由器、不能接交换机。**

## 2. 物料清单

| 东西 | 数量 | 说明 |
|---|---|---|
| 网线 | **3 根**（+2 备用） | A↔C、B↔D、C↔D。超五类（Cat5e）及以上，直通线，2~5 m |
| USB 转 RJ45 网卡 | **2 个**（+1 备用） | **只需要给 PC-C 和 PC-D**。买免驱的（RTL8153 / AX88179 芯片） |
| 手机 + 数据线 | 1 套 | 给 PC-A 提供外网（USB 共享网络） |
| 接收端 VT13 | 2 套 | 步兵插 PC-A，英雄插 PC-B |
| USB 扩展坞 | 1 个（可选） | PC-A 要占 2 个 USB 口（手机线 + VT13），口不够时用；**买带电源的** |

> **PC-A、PC-B 不需要 USB 网卡** —— 官方链路走的是笔记本自带的那个方形 RJ45 网口。

## 3. 第一阶段：配置路由器（只做一次）

### 3.1 登录路由器管理页

1. 手机或电脑连上这个 WiFi（默认密码看路由器背面）
2. 打开浏览器，地址栏输入路由器背面写的管理地址，常见的是
   `192.168.31.1`（小米）、`192.168.0.1`（TP-LINK/腾达）、`tplogin.cn`（TP-LINK 新版）
3. 输入管理密码登录

### 3.2 改 LAN 设置

1. 找到 **「高级设置」→「局域网设置」**（小米叫「DHCP 服务」，TP-LINK 叫「LAN 口设置」）
2. **LAN IP 地址**：改成 `192.168.1.1`
3. **子网掩码**：`255.255.255.0`
4. **DHCP 服务器**：**开启**
5. **地址池**：起始 `192.168.1.100`，结束 `192.168.1.249`（默认一般就是这个）
6. 点 **保存**

> 保存后路由器会重启、管理页会断开。用新地址 `http://192.168.1.1` 重新登录。

### 3.3 改无线设置

1. **「无线设置」→「2.4G WiFi」**
2. **WiFi 名称（SSID）**：自己起，比如 `RM26`。**只用英文和数字**，别用中文和空格
3. **密码**：`12345678`
4. **加密方式**：**WPA2-PSK**（不要选 WPA3，不要选「WPA2/WPA3 混合」）
5. **信道**：自动
6. 保存
7. 如果有 5G 开关：**可以关掉**，也可以另起一个名字 —— 主控只连 2.4G

### 3.4 WAN 口不用管

这套摆法里路由器**不上外网**，WAN 口空着就行。
PC-A 的外网由手机 USB 共享提供（见 4.1 第 4 步）。

### 3.5 判据

手机连 `RM26`，输入 `12345678`，连上后看手机 IP：
**必须是 `192.168.1.xxx`**，不能是 `192.168.31.xxx`。

> 如果路由器死活改不了 LAN IP（有些运营商定制机锁死了），这套摆法走不通 ——
> 主控固件里服务器地址写死 `192.168.1.2`，必须是 `192.168.1.0/24` 这个网段。换路由器。

## 4. 第二阶段：四台电脑逐台配置

> **每台机器都走同一套点法**，第一次看 4.1 第 2 步的完整版，后面各节只列「哪块网卡、填什么」：
>
> **开始菜单 → 控制面板 → 网络和 Internet → 网络和共享中心 →（左侧）更改适配器设置**
> →（或者 `Win + R` 输入 `ncpa.cpl` 回车）
> → **右键要点的那块网卡 → 属性 → 双击「Internet 协议版本 4 (TCP/IPv4)」
> → 选「使用下面的 IP 地址」→ 填 IP / 掩码 255.255.255.0 / 网关空 / DNS 空 → 确定 → 关闭**
>
> **顺序要求**：先把 ① ② ④（WiFi + 官方链路）全部配好、确认通，**再插 USB 转网卡配队友线**。
> 原因：`设置-队友网线.bat` 靠「哪块网卡已经有 `192.168.12.x`」来排除官方链路那块。
> **先把客户端的自带网口设成 `12.2`，脚本就不会认错。**

### 4.0 先把线插好

| 线 | 一头 | 另一头 |
|---|---|---|
| 线① | **PC-A 的自带 RJ45 网口** | **PC-C 的自带 RJ45 网口** |
| 线② | **PC-B 的自带 RJ45 网口** | **PC-D 的自带 RJ45 网口** |
| 线③（队友线，**先别插**） | PC-C 的 USB 转网卡 | PC-D 的 USB 转网卡 |

**怎么认「自带网口」**：笔记本侧面的方形网口，不用任何转接头，直接插网线。
插上后网口旁边的小灯会亮（常亮 + 闪）。

---

### 4.1 PC-A（官方端·步兵，同时跑引擎）

PC-A 有 **3 个网络**要配：WiFi（局域网）、自带网口（给 C）、手机共享（外网）。

#### 第 1 步：连 WiFi

1. 点屏幕右下角任务栏的**网络图标**（扇形 Wi-Fi 波形，Win11 在右边那排图标里）
2. 在列表里点 **`RM26`**
3. 勾选「自动连接」，点 **连接**
4. 输入密码 **`12345678`**，点 **下一步 / 确定**
5. 如果弹出「是否要让此电脑可被发现」→ 选 **是**（选否也不影响）

**判据**：任务栏网络图标变成 Wi-Fi 扇形，点开能看到「已连接到 RM26」。

#### 第 2 步：把 WiFi 网卡设成 `192.168.1.2`

1. **打开网络连接窗口**（两种走法，效果一样）：
   - **点鼠标**：开始菜单 → **控制面板** → **网络和 Internet** → **网络和共享中心**
     → 左侧点 **「更改适配器设置」**
   - **敲键盘**（快）：按 **`Win + R`** → 输入 **`ncpa.cpl`** → 回车
   打开后是一排网络图标。
2. **先认清楚哪个图标是哪个**（这一步很关键）：
   - 名为 **`WLAN`** 的图标 = **无线网卡**（图标上有 Wi‑Fi 信号格）
   - 名为 **`以太网`** 的图标 = **笔记本自带的方形网口**
   - 名为 **`以太网 2`** / `以太网 3` 的 = 后来插的 USB 网卡 / 手机共享
   - 名字里的数字会按插卡顺序变，**别背名字，靠图标样子和描述认**
     （右键图标 → 属性，最上面一行「连接时使用」写着型号）
3. **右键点 `WLAN` 图标 → 点「属性」**
   → 弹出「WLAN 属性」窗口，中间有一个带勾的列表
4. 在列表里找到并**双击** **`Internet 协议版本 4 (TCP/IPv4)`**
   → 弹出「Internet 协议版本 4 (TCP/IPv4) 属性」小窗口
5. 选中最上面的圆点 **「使用下面的 IP 地址」**（原本可能是「自动获得 IP 地址」）
6. 在框里填：

   | 框 | 填什么 |
   |---|---|
   | **IP 地址** | `192.168.1.2` |
   | **子网掩码** | `255.255.255.0`（鼠标点一下这个框会自动补全） |
   | **默认网关** | **什么都不填，留空** |
   | **首选 DNS 服务器** | 选 **「使用下面的 DNS 服务器地址」** 再留空，或保持「自动获得」都可以 |
   | **备用 DNS 服务器** | **留空** |

7. 点 **确定**（小窗口关掉）
8. 点 **关闭**（大窗口关掉）

> **为什么要留空网关**：这块网卡只负责和 `192.168.1.x` 里的主控、选手端通信，
> 全是同一个网段的直连，不需要网关。一旦填了 `192.168.1.1`，
> Windows 就会把「上外网」也往这条路上送，而路由器根本不通外网 → 引擎的外网测试红。

**判据**：`Win + R` → 输入 `cmd` → 回车 → 在黑色窗口里输入 `ipconfig` 回车。
在「WLAN」下面应该看到：

```
IPv4 地址 . . . . . . . . . . . . : 192.168.1.2
子网掩码  . . . . . . . . . . . . : 255.255.255.0
默认网关. . . . . . . . . . . . . : （空）
```

Windows 可能会提示「此网络未连接到 Internet」—— **正常，不用管**。

#### 第 3 步：把自带网口设成 `192.168.12.1`

1. 回到刚才那个网络连接窗口（没关就直接用；关了再 `Win + R` → `ncpa.cpl`）
2. **右键点 `以太网` 图标 → 点「属性」**
   > 不确定哪个是自带网口？**把插在它上面的网线拔掉** —— 哪个图标变成红叉，那个就是。
   > 插回去红叉消失。
3. 双击列表里的 **`Internet 协议版本 4 (TCP/IPv4)`**
4. 选中 **「使用下面的 IP 地址」**
5. 填：

   | 框 | 填什么 |
   |---|---|
   | **IP 地址** | `192.168.12.1` |
   | **子网掩码** | `255.255.255.0` |
   | **默认网关** | **留空** |
   | **首选 DNS 服务器** | **留空** |
   | **备用 DNS 服务器** | **留空** |

6. 点 **确定** → **关闭**

**判据**：`ipconfig` 里「以太网」下面应该看到 `192.168.12.1`。

#### 第 4 步：接手机共享网络（外网）

1. 用**数据线**把手机连到 PC-A 的 USB 口
2. 在手机上打开共享：
   - **安卓**：设置 → 网络和互联网 / 连接 → **热点与网络共享** → 打开 **USB 网络共享**
   - **iPhone**：设置 → 个人热点 → 打开，然后选 **仅 USB**
3. 回到电脑，`Win + R` → `ncpa.cpl`
   → 会**多出一个新图标**，名字叫 **`以太网 2`**（或「以太网 3」），描述是
   「**Remote NDIS based Internet Sharing Device**」/「远程 NDIS 兼容设备」
4. **这个图标什么都不要改。** 它默认就是「自动获得 IP 地址」，正合适。
5. **别认错图标**：以太网 1 = 自带网口（`12.1`），以太网 2 = 手机共享（自动），
   以太网 3 = 以后插的 USB 网卡。**靠描述区分最稳**（右键图标 → 状态里能看到描述）

**判据**：
- 任务栏网络图标变成 **地球 / 已连接 Internet**
- 打开浏览器能上任意网站

> **手机共享那个口断电就断网。** 现场把手机插着充电线，屏幕上关掉「闲置时断开共享」。

#### 第 5 步：验证 PC-A 三条网络全对

`Win + R` → `cmd` → 回车，依次输入：

```
ipconfig
```

应该**同时**看到这三个：

```
无线局域网适配器 WLAN:
   IPv4 地址 . . . . . . . . . . . . : 192.168.1.2

以太网适配器 以太网:
   IPv4 地址 . . . . . . . . . . . . : 192.168.12.1

以太网适配器 以太网 2:          ← 手机共享，地址是 192.168.x.x 或 172.20.x.x
   IPv4 地址 . . . . . . . . . . . . : 192.168.42.xx
```

然后：

```
route print
```

在输出的 **「IPv4 路由表」** 里找 **`0.0.0.0  0.0.0.0`** 这一行（叫「默认路由」）：

- ✅ **只有一行**，接口那一列指向手机共享那块网卡的地址（`192.168.42.x` 之类）→ 对了
- ❌ **有两行** → 说明某块网卡也填了网关，回去把它的「默认网关」清空
- ❌ **一行都没有** → 手机共享没生效，回去看第 4 步

#### 第 6 步：关掉 PC-A 的防火墙

1. 点 **开始菜单** → 输入 **`Windows Defender 防火墙`** → 回车
2. 左侧点 **「启用或关闭 Windows Defender 防火墙」**
3. 「专用网络设置」和「公用网络设置」两个都选 **「关闭 Windows Defender 防火墙」**
4. 点 **确定**

> 官方手册要求引擎所在电脑关闭本机防火墙，这是引擎启动的前置条件。
> 用命令行也行（管理员 cmd）：`netsh advfirewall set allprofiles state off`

#### 第 7 步：插步兵 VT13 接收端

1. 把步兵 VT13 插进 PC-A 的另一个 USB 口
2. 打开 **设备管理器**（`Win + X` → 设备管理器）→ 看「端口 (COM 和 LPT)」下面
3. 记下新出现的 **COM 号**（比如 `COM5`）
4. 打开官方选手端时选这个 COM

---

### 4.2 PC-B（官方端·英雄）

PC-B 有 **2 个网络**：WiFi（局域网）、自带网口（给 D）。不需要外网。

#### 第 1 步：连 WiFi（保持自动获取，不用改）

1. 点右下角网络图标 → 选 **`RM26`** → 输入密码 **`12345678`** → 连接
2. **不要动它的 IP 设置**，DHCP 自动拿 `192.168.1.xxx` 就行

> PC-B **不能**设成 `192.168.1.2` —— 那个地址是 PC-A（引擎那台）的。两个都设会冲突。

**判据**：`ipconfig` 里 WLAN 那块的 IPv4 是 `192.168.1.100`~`192.168.1.249` 之间的某个数。

#### 第 2 步：把自带网口设成 `192.168.12.1`

1. **开始菜单 → 控制面板 → 网络和 Internet → 网络和共享中心 → 左侧「更改适配器设置」**
   （或 `Win + R` → `ncpa.cpl`）
2. 右键点 **`以太网`** 图标（认不出就拔一下网线，看哪个变红叉）→ **属性**
3. 双击 **`Internet 协议版本 4 (TCP/IPv4)`**

## 5. 第三阶段：插队友线，验通

### 5.1 插线

现在 PC-C 和 PC-D 都已经有 USB 转网卡了，用**线③**把两块 USB 网卡连起来：

```
PC-C 的 USB 转网卡  ←────── 一根网线 ──────→  PC-D 的 USB 转网卡
```

**中间不接任何东西**：不接交换机、不接路由器、不接墙上的口。

### 5.2 判据：双向 ping

| 在哪台 | 打开 cmd 跑 | 期望 |
|---|---|---|
| **PC-C** | `ping 10.77.0.2` | 4 行回复，`时间<1ms` |
| **PC-D** | `ping 10.77.0.1` | 4 行回复，`时间<1ms` |

**两个方向都必须通。** 一端通一端不通 = 那边防火墙没放 ICMP（回去跑放行脚本）。

### 5.3 不通的时候按这个表查

| 现象 | 原因 | 怎么修 |
|---|---|---|
| USB 网卡插上，`ncpa.cpl` 里没有新图标 | 没被识别 | 换 USB 口（台式机插机箱后面）；设备管理器看有没有黄色感叹号 |
| 图标有，显示「网络电缆被拔出」 | 网线没插好 / 线坏 | 网口灯亮不亮；换一根线 |
| 图标有，IP 是 `169.254.x.x` | 没配 IP | 回去设 `10.77.0.1` / `.2` |
| IP 对了，ping 请求超时 | 对方防火墙拦 ICMP | 两端都跑 `防火墙-放行客户端端口.bat` |
| IP 对了，还是超时 | 两端 IP 一样 / 对方没设 | 各 `ipconfig` 看：必须一个 `.1` 一个 `.2` |
| ping 通但丢包 | USB 网卡插在无源 HUB 上供电不足 | 直插电脑 USB 口 |
| 换了 USB 口之后 IP 没了 | Windows 当成新网卡 | 重新设一次 IP |

### 5.4 确认视频端口

客户端**都打开之后**，在 PC-C 上跑（**cmd 窗口**里跑，PowerShell 里要先写 `powershell -c`）：

```cmd
powershell -NoProfile -Command "Test-NetConnection 10.77.0.2 -Port 47700 | Select-Object -ExpandProperty TcpTestSucceeded"
```

期望输出 **`True`**。
显示 `False` 有两种可能：PC-D 的客户端还没开（正常），或者链路没通（回去查 5.3）。

## 11. 这套摆法的已知风险

| 风险 | 影响 | 怎么办 |
|---|---|---|
| 引擎主机走无线连路由器 | 官方手册推荐有线；无线抖动会让「本地 IP 测试」和主控心跳偶发失败 | 这是官方「方案 2」允许的形态；现场多点两次测试。有条件时给 PC-A 拉一根网线到路由器 LAN 更稳 |
| 路由器没有外网 | 引擎的「外网连接测试」靠手机 | 手机插着充电线，关掉「闲置断开共享」 |
| 手机 USB 共享 | 手机锁屏/信号差会断 | 现场把手机放在信号好的地方 |
| 两台官方端都在 WiFi 上跑图传 | 2.4G 信道拥挤时丢包 | 路由器换干净信道；正式上场改走有线（见 `局域网联调手册.md` 第十二节） |
| 两块 USB 网卡跑 4~8 Mbps 队友流 | 长时间运行可能发热 | 摸一下烫就换个金属壳的 |
