# luojiamaster 使用说明

> 珞珈狐战队 · RM26 自定义客户端 —— 看实车第一视角 + 键鼠操控

---

> 📡 **不知道路由器/交换机/网线怎么接？** 见 [`局域网联调手册.md`](局域网联调手册.md)
> （第一~十节讲两机最小验证的接线和 IP；**四台电脑的现场摆法直接跳第十三节**，
> 现场照着点的是 [`现场施行手册-四台电脑-WiFi版.md`](现场施行手册-四台电脑-WiFi版.md)）


## 它能做什么

替代官方选手端，接入官方赛事引擎体系：

- 接收比赛数据（血量、时间、经济、增益等）
- 接收机器人第一视角图传（1080p）
- 发送键鼠控制指令操控实车
- 主画面 / 第二视角切换（H 键）

---

## 运行前必须准备的（缺一不可）

1. **裁判端**：`RoboMasterEngine` 已启动并登录，局域网网卡设 `192.168.1.2`
2. **官方选手端**：`RoboMasterClient` **版本必须 ≥ 12.0.0.213**
   - 已登录引擎
   - **图传画面正常显示**
   - 按 `P` → 键鼠控制来源 → 选 **自定义客户端**
3. 记下选手端登录的**机器人 ID**（luojiamaster 要用同一个）

> ⚠️ 旧版选手端（如 12.0.0.30）不支持该功能，`netstat` 查不到 3333 监听，无法连接。

---

## 启动步骤

1. 双击 `程序\luojiamaster.exe`
   （**要用队友视角**：先按下面「队友视角」一节把配置准备好，之后同样双击这个 exe 就行，
   **不需要 bat、不需要参数**）
2. 登录页 MQTT 服务端：**默认就是 `192.168.12.1:3333`，四台电脑摆法下不要改**。
   - 每台客户端和自己那台官方端是一根独立网线（`192.168.12.2` ↔ `192.168.12.1`），
     两台官方端的 `12.1` 同名不冲突，因为两根线中间没有交换机。
   - 只有「选手端和客户端在同一台电脑」时才填 `127.0.0.1:3333`。
3. 选队伍（红方/蓝方）
4. 选机器人（**必须与选手端一致**）
5. 点登录
6. 进入比赛界面后按 `Esc` 进入比赛模式

**没有实车、想先看界面？** `程序\` 里有现成的本地测试脚本：
`启动-本地测试-A.bat` + `启动-本地测试-B.bat` 开两个客户端，
再各开一个 `测试-本地视频源.bat` 喂假图传（回放 `测试画面.h265`，不用装 ffmpeg）。
进游戏界面按 `Esc`，登录按钮在没有裁判系统时点了不会进。步骤见
[`完整复现指南.md`](完整复现指南.md) 第 2.4 节。

## 队友视角（2027 赛季，两台客户端互联）

两台电脑各跑一个 luojiamaster，拉一根**专用网线**（`10.77.0.x`，不能和接官方端的那根共用网卡），
右上角小窗就能看到队友的第一视角。**不需要任何文件、不需要任何参数：双击 `luojiamaster.exe` 就有。**

### 怎么用（就这两句）

- 默认是 **A 机**（找 `10.77.0.2:47700`），标题条上标着 `[默认A]`。
- 另一台机器要当 B 机：**在队友小窗标题条上点一下 `[默认A]` 这个标签**，变成 `[B]`，
  就开始找 `10.77.0.1:47700`。选择会写回 exe 旁边的 `队友视角.ini`，下次打开还是 B。

小窗标题条上只有四样东西：`队友视角`、角色标签（`[默认A]` / `[默认B]` / `[A]` / `[B]`）、
连接状态（`未连接` / `已连队友` / `队友已连入` / `双向已连`）、`K 折叠` / `L 占主画面`。
`K` 折叠成一行；`L` 把队友画面铺满主画面，滚轮 1x~4x 放大，再按 `L` 退出。
小窗没信号时会直接把该连的 IP 写出来，省得翻文档。

### 什么时候才需要 `队友视角.ini`

平时不用。只有三种情况才需要它（exe 旁边，文件名就叫 `队友视角.ini`）：

| 想要的效果 | 怎么办 |
|---|---|
| 这台机器**永久固定**成 A 或 B 机 | 把 `程序\队友视角-A机.ini` / `-B机.ini` 复制成 `程序\队友视角.ini`；或双击 `程序\固定-A机.bat` / `固定-B机.bat` |
| 队友网不是 `10.77.0.x`（比如同机双实例测试） | 在 `队友视角.ini` 里写 `peer=<对方IP>:47700` |
| **不要**这个功能（回到没加它时的样子） | 双击 `程序\关闭-队友视角.bat`，或把 `程序\队友视角-关闭.ini` 复制成 `队友视角.ini` |

`队友视角.ini` 的格式（UTF-8，一行一项，`#` 开头是注释）：

```ini
role=A                   # 可选：A / B，地址跟着角色走
peer=10.77.0.2:47700     # 可选：写了就认它，不跟角色走
listen=47700             # 可选：默认 47700，两端必须一样
```

优先级：命令行 `--teammate-*` > `队友视角.ini` 里的 `peer=` > `role=` > 内置默认 A 机。
命令行参数只用于同机双实例测试（`启动-本地测试-A/B.bat`）——那时两台是 `127.0.0.1`，不跟角色走。

### 关掉之后是什么样

exe 旁边有 `peer=off` 的 `队友视角.ini` 时：**不出小窗、不占 47700、不注册 `K` / `L` / 滚轮**，
连一条灰色提示条都没有——和加这个功能之前完全一样。删掉 `队友视角.ini` 就恢复默认 A 机。

> 老办法照样能用（调试时方便）：
> `luojiamaster.exe --teammate-peer 10.77.0.2:47700 --teammate-listen 47700`

### 其余现场事项

- **不要重新编译**，`程序\luojiamaster.exe` 里已经有了。
- 两台都要先把自己那块队友网卡设成 `10.77.0.1` / `10.77.0.2`
  （`程序\设置-队友网线.bat` → `10.77.0.1`；`程序\设置-队友网线.bat B` → `10.77.0.2`，右键管理员运行）。
  **先插官方网线、设好 `192.168.12.2` 并 ping 通 `12.1`，再插队友网线跑这个脚本**，
  否则脚本分不清哪块是官方网卡。
- 两台都要跑一次防火墙脚本（`程序\防火墙-放行客户端端口.bat`，右键管理员运行）：
  放行入站 **TCP 47700**（队友视频）和 **UDP 3334**（官方图传）。少放 UDP 3334 的症状是
  「登录成功但主画面永远黑」。**官方端电脑上不要跑这个脚本。**
  默认启用后第一次双击 exe，Windows 可能会弹防火墙授权框，点「允许」即可；点了「取消」也能用，
  只是这一台收不到对方的画面。
- 不确定参数读进来没有？看 `程序\logs\<最新时间戳>\robogo.log` 里这几行之一：
  `队友视角使用内置默认（A 机）：peer=10.77.0.2:47700 listen=47700`、
  `队友视角参数来自 队友视角.ini：peer=... listen=47700`、
  `队友视角已在 队友视角.ini 里关闭（peer=off）`。
- **上现场前先跑一遍自检**：双击 `程序\现场自检-四台电脑.bat`（**不需要管理员**），
  它逐项打 `[OK]` / `[--]` / `[!!]`：两块网卡地址、官方链路 ping、队友链路 ping、
  路由器/裁判端、两条防火墙规则、3333/47700 端口、`队友视角.ini`（可选）、exe 的 MD5。
  两台客户端的 **exe MD5 必须一模一样**。
- **单客户端只支持一个队友**。另外队友画面冻结超过 5 秒，小窗会打「画面已断」，
  但**解出来的最后一帧还会留在墙上**（不会变黑），看到旧画面别以为还在传。
  完整判读表在 [`局域网联调手册.md`](局域网联调手册.md) 12.8。

四台电脑标准摆法（PC-A/B 两台官方端、PC-C/D 两台客户端，步兵一台英雄一台）的完整接线、
IP 表、启动顺序和判读表，见 [`局域网联调手册.md`](局域网联调手册.md) **第十三节**
（现场点鼠标的完整版是 [`现场施行手册-四台电脑-WiFi版.md`](现场施行手册-四台电脑-WiFi版.md)）；
第二台电脑只需要 clone + 双击 exe，步骤见
[`完整复现指南.md`](完整复现指南.md) 第 2.5 节；
实现原理和已知限制见 [`档案/阶段6-队友视角-互联-2026-11-02.md`](档案/阶段6-队友视角-互联-2026-11-02.md)。

## 快捷键

| 键 | 功能 |
|---|---|
| `Esc` | 进入 / 退出比赛模式（**只有进入后才会发送键鼠**） |
| `H` | 主画面 / 第二视角切换 |
| `I` | 主画面 180° 翻转 |
| `P` | 设置面板（调鼠标灵敏度） |
| `K` | 队友小窗 折叠 / 展开（队友视角开着时才有，见上一节） |
| `L` | 队友画面 接管 / 退出主画面（同上） |
| 滚轮 | 队友画面接管主画面时 1x~4x 中心放大（同上） |

> 只有队友视角被显式关掉（`队友视角.ini` 里写 `peer=off`）时，`K` / `L` **根本不注册**，
> 原有按键一个都不受影响。默认（双击 exe）`K` / `L` 是队友小窗的按键——
> 它们本来就不发给机器人（发给机器人的只有 WASD/Shift/Ctrl/QE/RF/GZXCVB）。

> 所有按键都只对**当前窗口**生效。开两个客户端时，先点一下要操作的那个窗口。
> **不要按 CTRL**：固件把 CTRL 当整车复位。

## 鼠标灵敏度

按 `P` 打开设置面板，拖动「鼠标灵敏度」滑块（范围 0.05 ~ 3.0，默认 0.4）。

按手感调，觉得转太快就调小。

## 常见问题

**连不上服务器**
- 检查选手端版本是否 ≥ 12.0.0.213
- 选手端是否已登录引擎
- 关闭防火墙（Windows Defender + 第三方安全软件）
- 地址是否正确（同机 `127.0.0.1`，异机用选手端 IP）

**连上了但画面黑**
- 选手端图传是否正常显示
- 机器人 ID 是否与选手端一致

**有画面但车不动**
- 选手端 P 面板 → 键鼠控制来源 → 是否选了「自定义客户端」
- 是否已按 `Esc` 进入比赛模式
- 比赛是否处于允许操作的阶段

**画面是倒的**
- 按 `I` 翻转

**键盘完全没反应**
- 请使用本包内的 exe（已修复原版键盘采样 bug）
