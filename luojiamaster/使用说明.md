# luojiamaster 使用说明

> 珞珈狐战队 · RM26 自定义客户端 —— 看实车第一视角 + 键鼠操控

---

> 📡 **不知道路由器/交换机/网线怎么接？** 见 [`局域网联调手册.md`](局域网联调手册.md)
> （路由器和交换机怎么插、三台电脑 IP 怎么设、防火墙怎么放行，全在里面）


## 它能做什么

替代官方选手端，接入官方赛事引擎体系：

- 接收比赛数据（血量、时间、经济、增益等）
- 接收机器人第一视角图传（1080p）
- 发送键鼠控制指令操控实车
- 主画面 / 第二视角切换（H 键）

---

## 运行前必须准备的（缺一不可）

1. **裁判端**：`RoboMasterEngine` 已启动并登录，局域网网卡设 `192.168.1.2`
2. **官方选手端**：`RoboMasterClient` **版本必须 ≥ 12.0.0.213**
   - 已登录引擎
   - **图传画面正常显示**
   - 按 `P` → 键鼠控制来源 → 选 **自定义客户端**
3. 记下选手端登录的**机器人 ID**（luojiamaster 要用同一个）

> ⚠️ 旧版选手端（如 12.0.0.30）不支持该功能，`netstat` 查不到 3333 监听，无法连接。

---

## 启动步骤

1. 双击 `程序\luojiamaster.exe`
2. 登录页 MQTT 服务端填：
   - 选手端与本程序在同一台电脑：`127.0.0.1:3333`
   - 在不同电脑：`选手端IP:3333`
3. 选队伍（红方/蓝方）
4. 选机器人（**必须与选手端一致**）
5. 点登录
6. 进入比赛界面后按 `Esc` 进入比赛模式

---

## 快捷键

| 键 | 功能 |
|---|---|
| `Esc` | 进入 / 退出比赛模式（**只有进入后才会发送键鼠**） |
| `H` | 主画面 / 第二视角切换 |
| `I` | 主画面 180° 翻转 |
| `P` | 设置面板（调鼠标灵敏度） |

---

## 鼠标灵敏度

按 `P` 打开设置面板，拖动「鼠标灵敏度」滑块（范围 0.05 ~ 3.0，默认 0.4）。

按手感调，觉得转太快就调小。

## 常见问题

**连不上服务器**
- 检查选手端版本是否 ≥ 12.0.0.213
- 选手端是否已登录引擎
- 关闭防火墙（Windows Defender + 第三方安全软件）
- 地址是否正确（同机 `127.0.0.1`，异机用选手端 IP）

**连上了但画面黑**
- 选手端图传是否正常显示
- 机器人 ID 是否与选手端一致

**有画面但车不动**
- 选手端 P 面板 → 键鼠控制来源 → 是否选了「自定义客户端」
- 是否已按 `Esc` 进入比赛模式
- 比赛是否处于允许操作的阶段

**画面是倒的**
- 按 `I` 翻转

**键盘完全没反应**
- 请使用本包内的 exe（已修复原版键盘采样 bug）
