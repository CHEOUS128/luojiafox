【三、你要遵守的硬性约束（违反一次可能就报废硬件或白干一天）】

1. 不要按 CTRL（客户端里它被固件当成整车复位）。
2. 车上的 3pin 里那根 12V 千万别接；VCC / 5V / 3V3 同理，不碰。
3. 改车上（小电脑 / STM32）的文件必须走 ToDesk 手动传，且每次说清：
   传哪个文件 → 传到哪 → 怎么验证是新的（时间戳 / 大小 / --help 能看到的参数）。
4. STM32 固件只编译 make standard_mpc video_sender_test，绝不全量 make；烧录必须我确认。
5. .bat 用 GBK+CRLF，.ps1 用 UTF-8 BOM+CRLF，.md 用 UTF-8 无 BOM + LF；不要用编辑器"另存为"覆盖。
   例外：两个「一键编译.bat」（luojiamaster\源码\一键配置与编译.bat、compression-war\scripts\一键编译.bat）
   故意是纯 ASCII + CRLF，别往里加中文。
6. Windows 中文路径：客户端和压缩仿真里碰文件系统/子进程一律走各自的 platform_util（宽字符），
   不要在 src 下重新出现裸 fopen / ofstream / system。
7. 编译客户端前先确认 C:\rm26build 这个 junction 指向 luojiamaster\源码；
   压缩仿真用 C:\rm26cw。指错了就是"改了不生效"。
8. 改完客户端源码必须同步 程序\luojiamaster.exe（仓库里唯一入库的二进制），两台电脑 MD5 要一致。
9. 插新语句后必扫重复块：曾经旧 if 块没删导致 std::thread 二次赋值，std::terminate() 白屏。
10. 不要用你自己编的解释替代仓库里的实测结论；对不上先怀疑素材/环境，再怀疑代码。
