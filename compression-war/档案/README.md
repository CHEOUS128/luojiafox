## 已被替代的口径

| 原口径 | 当前结论 |
|---|---|
| 实时每帧最多8包，VBV18944 bit | 所有帧含IDR最多2包/592 B，VBV4736 bit；不允许第三包 |
| 用全程平均帧率证明操作手视角流畅 | 正常60秒窗口去掉启动/收尾后，每个完整1秒实际提交至少15张新图 |
| 只看画面或PNG大小判断是否经过限速 | 捕获309 B外层帧与收到的300 B数据，独立重放逐帧像素核对 |
| 旧离线播放器能证明真实在线性能 | 离线仅保留对账；实际在线耗时与显示必须由cw_live窗口测量 |

历史数据不改写。后续推翻结论时，在此表追加更正，并把当前入口指向新的唯一基线。
